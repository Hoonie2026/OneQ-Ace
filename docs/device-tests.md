# 실기기 결과표

단계 게이트마다 이 표를 채운다(개발기준서 9.4). 앱 화면의 **결과 복사** 내용을 그대로 붙여 넣으면 된다.

## 0단계 — 실기기 저장 검증

**게이트**: Android(본인 기기) 전 항목 통과 필수. iPhone은 동료 기기로 보조 확인. 실패 항목은 D1(PWA) 재검토.

| ID | 항목 | 방법 | 판정 |
|---|---|---|---|
| T1 | 홈 화면 설치·실행 | 브라우저 메뉴로 설치 → 홈 화면 아이콘으로 열기 | 자동 |
| T2 | 오프라인 실행 | 비행기 모드 켜고 앱 열기 | 자동 |
| T3 | 영구 저장 요청 | 버튼 | 자동(거부 시 확인 필요) |
| T4 | 사용량 표시 | 버튼 | 자동 |
| T5 | 30MB 더미 팩 저장·읽기 | 버튼(100장 × 300KB, 전수 SHA-256 검증) | 자동 |
| T6 | 재실행 후 유지 | T5 후 최근 앱 목록에서 앱 닫기 → 다시 열기 | 자동 |
| T7 | zip 팩 가져오기·이미지 표시 | ① 샘플 팩 받기 → ② 팩 가져오기에서 그 파일 선택 → 미리보기 확인 | 사용자 확인 |
| T8a | 백업 — 공유 시트 | 공유 시트 → 파일/드라이브에 저장 (`.txt`로 내보냄 — 아래 발견 사항 참고) | 사용자 확인 |
| T8b | 백업 — 다운로드 | 다운로드 폴더에 생겼는지 확인 | 사용자 확인 |
| T9 | 백업 파일 읽기 | T8에서 저장한 `.json` 또는 `.txt` 선택 | 자동 |

## 3단계 — 학습앱 코어 (앱 v0.1)

**게이트**: 비행기 모드에서 1회차 완주, 백업 → 앱 삭제 → 복원 후 기록 100% 일치. Android(본인 기기) 필수.

**준비**: 새 버전으로 업데이트(상단 "새 버전이 있습니다" → 지금 업데이트). 샘플팩 `oneq-SURVEY-2022-1.zip`을 휴대폰으로 옮겨 둔다(메신저 나에게 보내기·드라이브 등).

| ID | 항목 | 방법 | 판정 |
|---|---|---|---|
| S1 | 팩 가져오기 | 홈 → 문제팩 가져오기 → zip 선택 → "2022년 1회 100문항" 알림 | |
| S2 | 오프라인 완주 | 비행기 모드 켜고 앱 열기 → 회차 풀기 → 100문항 끝까지 → 결과 화면 | |
| S3 | 이어 풀기 | 풀이 중간에 앱을 완전히 닫았다 열기 → 홈 "이어서 풀기"가 같은 문항에서 시작 | |
| S4 | 확대 | 두 손가락 확대, 두 번 탭 확대/원래대로, + − 버튼. 긴 그림 문항(예: 2021-3회 72번)은 스크롤 | |
| S5 | 가로 회전 | 풀이 중 가로로 돌리면 문항 왼쪽, 보기 오른쪽 | |
| S6 | 채점 기록 | 모름·헷갈림·한 줄 설명이 저장되고, 결과 화면 맞힘·틀림·모름 합이 100 | |
| S7 | 백업(다운로드) | ⚙ 백업·설정 → 지문(예: `풀이 100건 · 메모 1건 · 지문 1a2b3c4d`)을 적어 둠 → 백업 파일 저장 → 다운로드 폴더 확인 | |
| S8 | 백업(공유, 보조) | 공유로 보내기 → 드라이브/메신저에 **내용 있는** .txt가 생기는지(0단계 T8a 재확인) | |
| S9 | 앱 삭제 → 복원 | 앱 삭제(또는 Chrome 사이트 데이터 삭제) → 다시 설치 → 설정 → 백업 파일에서 복원 → "백업과 기록 일치", 지문이 S7과 같음 | |
| S10 | 팩 다시 가져오기 | 복원 후 같은 팩을 가져오기 → "기록 101건 이어짐", 진도 100/100, 매핑 대기 0건 | |
| S11 | 저장 실패 경고 | (선택) 저장공간이 거의 찬 기기에서 팩 가져오기 → 화면 위 빨간 경고가 닫기 전까지 유지 | |
