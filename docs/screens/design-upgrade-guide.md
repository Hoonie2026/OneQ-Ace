## 1. 왜 실기기 화면이 여전히 "가내수공업"처럼 보이는가? (핵심 원인 5가지)

실기기 캡처 14장을 상용 에듀테크·핀테크 앱(토스, 스픽, 콴다)과 1:1로 대조한 결과, 기능과 알고리즘은 훌륭함에도 시각적으로 투박해 보이는 원인은 다음 **5가지 구조적 미스매치**에 있습니다.

1. **"테두리(Border) 중첩"으로 인한 격자 철망 현상 (Box-in-a-Box)**
   - 상용 앱(토스 TDS 등)은 카드를 구분할 때 **외곽선(`border`)을 쓰지 않고 배경 면의 명도 차이(Tonal Surface)**만 사용합니다.
   - 반면 현재 앱(특히 다크 모드 캡처 `195131329.jpg`)은 **카드 바깥에 테두리(`1px` 또는 `2px 파란선`)를 치고, 그 카드 안의 버튼(`과목별 학습 ›`, `모의고사 ›`)에 또 테두리를 치고, 보기 버튼(`①②③④`) 안에 또 동그라미 테두리**가 들어가 있어 화면 전체가 '사각 틀 안의 사각 틀'로 쪼개져 보입니다.
2. **수제(Hand-coded) 직선 SVG 아이콘과 텍스트 기호(`›`, `▾`, `☞`, `①`)의 혼재**
   - v0.9.0(다크 모드 캡처)에서 이모지(`📊`, `🔎`, `📘`)를 걷어낸 방향은 좋았으나, 직접 좌표를 찍어 만든 직선 위주 SVG가 들어가면서 **설정 버튼이 '기어(톱니)' 대신 '음향/검색 필터 슬라이더(`🎚️`)'로 바뀌고**, **성적 아이콘이 막대 차트가 아니라 '산(山)' 한자나 삼지창**처럼 보입니다(`195358790.jpg`).
   - 게다가 한 화면 안에서조차 **SVG 아이콘**, **유니코드 꺾쇠(`›`)**, **유니코드 삼각형(`▾`)**, **유니코드 원문자(`①②③④`)**가 뒤섞여 있어 기호마다 선 굵기와 크기가 제각각입니다.
3. **한국어 어절 줄바꿈(`word-break: keep-all`) 누락으로 인한 '외톨이 한 글자' 참사**
   - 실기기 캡처에서 가장 눈에 띄는 아마추어적 요소는 **글자 하나가 아래 줄로 뚝 떨어지는 현상**입니다.
     - `195204720.jpg`(학습 계획): 우측 `[추가]` 버튼이 좁아져 세로로 **`추` / `가`** 두 줄로 깨짐
     - `194819789.jpg`(시스템 추천 학습): **`오늘 추천 20문` / `항`** 과 **`남은 분` / `량`** 이 동시에 한 글자씩 떨어짐
     - `194803983.jpg` · `195223886.jpg`(예상 점수 계산): **`(보유 기출 31회차 기` / `준)`** 에서 `준)`만 다음 줄로 떨어짐
4. **하위 화면 진입 시 '이중 헤더(Double Header)' 노출**
   - `학습 계획`(`195204720.jpg`)에는 맨 위에 `[‹ 홈] 학습 계획`만 나오는데, `예상 점수 계산`(`195223886.jpg`)과 `시스템 추천 학습`(`195312959.jpg`)에는 맨 위에 **`[1Q] 원큐합격` 로고 헤더가 그대로 박혀 있고 그 아래에 또 `[‹ 홈] 예상 점수 계산` 헤더**가 나옵니다. 상단 22%가 헤더 2개로 낭비되어 앱이 아니라 웹 문서처럼 보입니다.
5. **글자 크기 20단계 난립과 밑줄(`underline`)·원색 테두리 남용**
   - CSS 내에 `11px`부터 `34px`까지 **20가지 글자 크기**가 미세하게 다르게 흩어져 있어 화면마다 글자 크기가 들쭉날쭉해 보입니다.
   - 또한 수험표의 `"학습계획 설정(재설정)"`처럼 모바일 앱에서는 거의 쓰지 않는 **웹 하이퍼링크식 밑줄(`text-decoration: underline`)**이 괄호 `()`를 관통하고 있어 구식 웹사이트 인상을 줍니다.

### 3-4. [풀이 화면] 문제 이미지 여백과 하단 조작부의 시각적 일체감 완성

실기기 캡처 `194836394.jpg`(화이트)와 `195358790.jpg`(다크)에서 보이는 풀이 화면의 어색함을 해결하는 방법입니다.

1. **문제 이미지(`94. 그림과 같이...`) 내부 여백(Safe Padding) 확보**
   - 기출문제 원본 이미지들은 좌우 여백이 거의 없이 크롭되어 있어, 이미지 박스에 넣으면 문항 번호 `94.`가 왼쪽 모서리에 바짝 붙어 보입니다.
   - `.zoom-inner img` 자체에 **`padding: 12px 14px; background: var(--paper); border-radius: 12px;`**(화이트 모드에서는 `box-shadow: 0 1px 4px rgba(0,0,0,0.06)`)를 주면 문제 이미지 사방에 깨끗한 시험지 여백이 생겨 가독성과 품격이 크게 높아집니다.
2. **하단 `모름` · `웹검색` 버튼의 원색 테두리 충돌 해소**
   - 현재 `모름`은 주황/노란 테두리, `웹검색`은 파란 테두리로 서로 다른 색상의 외곽선 박스 2개가 나란히 있어 시선을 어지럽힙니다.

## 4. 우선순위별 디자인 업그레이드 체크리스트 요약

1. **[최우선 · 조판 버그 수정]** 모든 버튼에 `white-space: nowrap; flex-shrink: 0;` 적용(`학습 계획`의 **`추/가`** 세로 깨짐 해결) 및 전역 `word-break: keep-all` 적용(`오늘 추천 20문/항`, `남은 분/량`, `31회차 기/준)` 외톨이 글자 해결).
2. **[최우선 · 이중 헤더 제거]** 홈 내부 서브뷰(`예상 점수 계산`, `시스템 추천 학습`, `과목별 학습`, `모의고사`, `학습 원리`) 진입 시 상단 `1Q 원큐합격` 헤더를 숨기고 `[‹ 홈] 화면 제목` 단일 헤더만 표시.
3. **[상 · 아이콘/기호 정밀화]** 우측 상단 설정 아이콘을 '슬라이더'에서 **정밀 기어(Cog) SVG**로 교체, `[성적]` 아이콘을 둥근 막대 차트로 교체, 보기 단추의 유니코드 원문자(`①②③④`)를 **단독 숫자(`1 2 3 4`)**로 교체, 블록 버튼의 불필요한 텍스트 `›` 제거 및 아코디언 `▾`을 SVG Chevron으로 통일.
4. **[상 · 테두리 제거(Tonal Surface)]** 다크/화이트 모드의 카드 외곽선(특히 `오늘 학습 목표`의 2px 파란 테두리)과 보조 버튼 외곽선을 걷어내고 **배경 명도 차이(Surface Elevation)**로만 계층 구분.
5. **[중 · 수험표 & 풀이 화면 디테일]** 수험표의 `"학습계획 설정(재설정)"` 밑줄을 제거해 반투명 캡슐 버튼으로 변경(노란색은 `D-day`에만 집중), 풀이 화면 문제 이미지에 `12px` 시험지 내부 여백 부여, 하단 `모름`·`웹검색` 원색 테두리를 차분한 면 버튼으로 전환.
