# 원큐합격 학습앱 사용 안내

기사·산업기사 **객관식 필기** 기출을 시험일까지의 계획에 맞춰 풀게 해 주는 앱입니다. 서버 없이 기기 안에서만 동작하고, 모든 기록은 그 기기에만 저장됩니다.

## 1. 설치

앱 주소: `https://hoonie2026.github.io/OneQ-Ace/` — 주소를 열면 기기에 맞는 설치 안내가 나옵니다.

| 기기 | 브라우저 | 설치 |
|---|---|---|
| 안드로이드 | Chrome | [원큐합격 앱 설치] → 설치. 아이콘은 앱 목록에 생깁니다(홈 화면에 없으면 앱 목록에서 길게 눌러 「홈 화면에 추가」) |
| 아이폰·아이패드 | Safari | 공유(□↑) → 「홈 화면에 추가」 → 홈 화면 아이콘으로 열기 |
| PC | Chrome | 주소창의 설치 아이콘 또는 첫 화면 안내 |

카카오톡 등 앱 안 브라우저에서는 설치가 안 되고 기록도 따로 저장됩니다. 안내에 따라 Chrome(아이폰은 Safari)으로 여세요.

## 2. 처음 시작

1. **문제팩 등록하기** — 원큐합격 문제팩 생성기(PC)로 만든 문제팩(.zip)을 고릅니다. 앱에는 문제팩이 들어 있지 않습니다.
2. **학습계획 설정** — 홈 위 수험표의 [학습계획 설정]에서 시험일, 1주당 학습일, 하루 학습시간을 정합니다. 특정 날짜만 학습시간을 다르게(집중하는 날·쉬는 날) 넣을 수도 있습니다.

## 3. 홈 화면

- **수험표**: 시험일과 남은 날(D-day). 여러 종목이면 위쪽 종목 상자를 눌러 바꿉니다.
- **누적 점수**: 지금까지 푼 문항 중 정답 비율(같은 문항은 가장 최근 답 기준).
- **시험일 예상 점수**: 과목마다 처음 푼 문항이 10개 이상 쌓이면 표시됩니다(그 전에는 "측정 전"). 지금까지의 성적으로 남은 기간 계획대로 공부할 때의 예상입니다. [계산 보기]에서 계산 방법과 과목별 점수를 봅니다.
- **오늘 학습 목표**: 계획에 맞춰 오늘 풀 문항 수.
- 학습 방식 네 가지:
  - **시스템 추천 학습** — 앱이 오늘 틀린 문항, 잊을 때가 된 복습, 새 문항(과락 위험이 큰 과목에 많이)을 골라 줍니다.
  - **과목별 학습** — 과목을 골라서.
  - **회차별 학습** — 기출 한 회차를 시험지 순서대로 처음부터 끝까지. 중간에 나가도 이어서 풀고, 다 풀면 성적과 합격선을 보여 줍니다.
  - **모의고사** — 실제 시험처럼 과목별 문항 수·시간으로.
- **출제기준**, **학습 원리 · 예상 점수 계산 방법**: 종목 출제기준과 앱이 쓰는 학습 방법의 근거.

## 4. 문제 풀기

- 보기를 고르면 바로 정답·오답이 나옵니다. 모르면 찍지 말고 **모름**, 너무 쉬우면 **쉬움**(다음 복습이 멀어짐).
- 시스템 추천·과목별 학습은 한 묶음이 끝나면 틀리거나 모른 문항을 그 자리에서 한 번 더 풉니다.
- 답한 뒤 **메모 쓰기**(같은 문항을 다시 풀 때 보임), **웹검색**(문항의 핵심 문장을 구글 AI 모드로 보내 개념·풀이 설명 받기).
- 보기 아래 **[계산기] [메모]**: 공학용 계산기(도·분·초 포함)와 손글씨 연습장.
- 같은 문항이 여러 회차에 나왔으면 "n회 출제"가 보입니다.
- PC 키보드: 1~4 보기, M 모름, E 쉬움, Enter 다음, ← 이전.

### 정답이 없거나 확실하지 않은 문항

스캔 상태 때문에 문제팩에 정답이 없거나(정답 미지정), 정답이 확실하지 않은(정답 확인 필요) 문항이 있을 수 있습니다.

- 보기를 고른 뒤 **[정답 지정하기]**(미지정) 또는 **[정답 고치기]**(확인 필요)를 누르고 정답 번호를 고릅니다.
- 한 번 지정한 정답은 다른 회차의 같은 문항(보기 순서까지 같은 문항)에도 반영되고, 학습기록을 지워도 남습니다(다음부터는 [정답 고치기]).
- 스캔본 문제팩처럼 보기 순서가 다를 수 있는 같은 문항은 자동으로 옮기지 않고, "참고: 같은 문항으로 묶인 ○○년 ○회 문항의 정답은 ③"과 [그 문항 보기]로 비교해 정하게 합니다.
- 정답이 없는 문항은 모의고사에 나오지 않습니다.

## 5. 문제팩·학습기록 설정(홈 오른쪽 위 ⚙)

- **문제팩 관리**: [문제팩 등록하기], 종목별 등록 현황(회차·문항 수).
- **학습기록 관리**: [학습기록 백업하기](다운로드 폴더에 파일 저장)와 마지막 백업 날짜, [백업파일 업데이트(학습기록 가져오기)].
  - 학습기록은 그 기기의 브라우저 저장소에 있어, 브라우저의 인터넷 사용 기록·쿠키 및 사이트 데이터를 지우면 함께 지워집니다. 정기적으로 백업하세요.
  - 다른 기기에서 이어서 공부하려면: 이전 기기에서 백업 → 파일을 옮김 → 새 기기에서 같은 문제팩 등록 → [백업파일 업데이트]. 같은 풀이는 한 번만 들어갑니다.
- **데이터 초기화**: 학습기록만 초기화 · 문제팩 지우기 · 자격종목 지우기(모든 종목을 고르면 이 기기 전체).
- **원큐합격 앱 정보**, **원큐합격 앱 설치 안내**(링크 복사·공유, 문제팩 생성기 안내).

## 6. 시험일 예상 점수는 어떻게 계산하나

실제 시험 문항을 **보유 기출과 같은 문항 / 숫자·표현만 바꾼 변형 / 처음 보는 문항**으로 나누고(넣은 기출을 회차끼리 대조해 비율을 잼), 각 몫을 맞힐 확률을 더합니다.

- 같은 문항: 시험일 아침의 기억률(FSRS 기억 모형 + 내 풀이 기록)
- 처음 보는 문항: 최근 처음 푼 문항 30개의 정답률(모름은 찍기 25%) + 기출을 익히면서 오르는 몫(전이)
- 변형: 둘 사이

자세한 산식·근거·오차 범위는 앱의 [계산 보기]에 있습니다. 예상 점수는 합격을 보장하는 숫자가 아니라 계획대로 공부할 때의 어림값입니다.
