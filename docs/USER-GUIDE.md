# 원큐합격 사용 안내 (초안)

8단계 출품 때 설치 가이드 1장으로 다듬는다. 실기기 시험에서 나온 질문을 여기에 모은다.

## 학습 방법 (v0.7)

- 홈: **시험일 | D-day**, **현재 점수 | 시험일 예상 점수**, **오늘 학습 목표**(오른쪽에 계획한 시간·문항), 그 아래 **모의고사**.
- **시스템 추천 학습**: 누르면 오늘 무엇을 풀지(오늘 틀린·모름 다시, 지난번 틀린·모름, 맞혔지만 다시 볼 문항, 새 문항)와 이유가 먼저 나오고, **학습 시작**을 누르면 앱이 골라 냅니다.
  틀린 문항이 쌓여도 새 문항을 계속 풀 수 있게 **복습은 한 번에 최대 60%**까지만 내고, 맞힌 문항도 찍어서 맞혔을 수 있으니 가끔 다시 냅니다. 다 풀면 틀린·모름 문항이 바로 한 번 더.
- **과목별 학습**: 과목마다 현재 점수 ☞ 시험일 예상 점수, 풀이 횟수·마지막 날짜. **학습하기**를 누르면 그 과목의 복습 + 새 문항 15문항.
  진도율(풀어 본 비율)은 쓰지 않고 점수로 보여 줍니다.
- **오늘 학습 마치기**: 오늘 푼 결과와 점수, 합격선에 못 미치면 학습 계획을 고칠지 묻습니다.
- **시험일 예상 점수가 70점 미만**이면 "계획 수정 필요" 배지. 같은 문항이 여러 회차에 나왔으면 문항 오른쪽 위에 **"n회 출제"**.
- 풀이 화면 아래 **모름 | 🔎 웹검색**: 처음 보는 개념은 웹검색을 누르면 문항의 핵심 낱말로 **구글 AI 모드**가 새 탭에 열려 개념을 설명해 줍니다(답한 뒤에도 같은 웹검색 단추). 검색하고 나서 답하면 "자신 없이 맞힘"으로 기록돼(맞혀도 복습이 조금 빨리 돌아옴) 실력이 부풀려 계산되지 않습니다. 모의고사에는 없습니다.
- 답한 뒤 **✎ 메모 쓰기**: 개념·풀이 요령을 적어 두면, 그 문항(다른 회차의 같은 문항 포함)을 다시 풀 때 위에 **📝 메모 있음**(보라색)이 보이고 답한 뒤 메모가 나옵니다.
- 여러 종목이면 홈 위 **자격종목** 드롭다운에서 고릅니다.
- **오늘 학습 목표**를 채우면 풀이 화면에 "🎉 오늘 학습 목표 달성"과 오늘 결과(푼 문항·정답·오답·모름·성적)가 나옵니다. **계속 학습하기**를 고르면 오늘 기록을 바탕으로(오늘 틀린·모름 문항부터) 이어서 추천하고, 과목별 학습 중이었다면 그 과목을 이어 갑니다.
- 도중에 **오늘 학습 마치기**를 고르면 푼 기록은 그대로 남고, 홈은 "이어서 학습" 대신 **시스템 추천 학습**으로 바뀝니다.
- 과목별 학습의 막대는 **시험일 예상 점수**, 진한 세로선은 **현재 점수**, 점선은 과락선입니다.
- 문제팩 가져오기는 **설정**에서, 지우기는 **설정 → 이 기기 데이터 지우기**에서 합니다.

## 학습 계획과 점수

- 홈의 **학습 계획 정하기**에서 시험일·하루 학습시간·일주일에 공부하는 날을 정합니다. 평소와 다른 날(휴가·시험 직전 집중)은 **날짜별 학습시간**에 적습니다.
- **현재 점수** = 지금까지 답한 그대로(안 푼 문항·모름·오답 0점).
- **시험일 예상 점수**(v0.7, ADR 013) = 계획대로 공부하고 실제 시험을 봤을 때. 실제 시험 문항을 셋으로 나눠 계산합니다.
  - **같은 기출**: 가지고 있는 기출과 거의 같은 문항 → 그 기출을 익힌 만큼 맞힘
  - **변형 기출**: 숫자·표현만 바꾼 같은 개념 → 원래 기출을 익혔으면 대부분 맞힘
  - **처음 보는 문항**: 과목별 최근 첫 풀이 정답률(검색 후 맞힌 것·모름은 찍기 25%로) + 기출을 많이 익힐수록 조금 오름
  - 비율은 가진 기출에서 직접 잽니다(측량 31회차: 같은 약 32% · 변형 약 23% · 처음 약 45%). 기출 회차가 적으면 비율이 낮아져(2회차면 3% 안팎) 시간을 늘려도 점수가 거의 오르지 않습니다.
- 같은 개념의 변형 문항은 한 번 익히면 적은 노력으로 함께 익힌다고 보고, 과목은 낮은 과목부터 고르게 올린다고 봅니다(과락 방지).
- **시험 전 3일**의 학습시간은 이미 익힌 문항을 마지막으로 다시 보는 데 먼저 씁니다(시험일 기억률 상승). 학습 계획 화면에 "날짜별 학습시간 반영: +○시간 → +○점"으로 따로 보입니다.
- 풀이 기록이 없을 때는 처음 보는 문항을 모두 찍는다(25%)고 가정한 값입니다. 풀기 시작하면 내 정답률로 바뀝니다.

## 모의고사

- 가지고 있는 기출 전체에서 과목별 실제 문항 수만큼, 자주 나온 문항일수록 잘 뽑히게 출제합니다. 시험시간은 문항당 1분 30초(100문항 2시간 30분).
- **모의고사 성적은 모의고사 이력에만** 남고 현재 점수·시험일 예상·학습 추천에는 넣지 않습니다.
- 풀이 중에는 정답을 보여 주지 않습니다. **제출**하거나 시간이 끝나면 채점하고(안 푼 문항 0점), 성적은 모의고사 탭에 쌓입니다.
- ✕로 나가면 남은 시간이 멈추고, 모의고사 탭에서 이어서 열면 그때부터 다시 흐릅니다(앱을 강제로 닫으면 계속 흐름).

## 문제팩

**같은 팩인지는 파일 이름이 아니라 팩 안의 내용으로 판단합니다.**

| 가져온 팩 | 앱의 동작 | 학습 기록 |
|---|---|---|
| 처음 보는 회차(종목·연도·회차가 다름) | 추가 | 회차별로 따로 쌓임 |
| 이미 있는 회차, 내용까지 똑같음 | 건너뜀("같은 팩 N개는 건너뜀") | 그대로 |
| 이미 있는 회차, 버전이 더 높음(다시 전처리한 팩) | 새 팩으로 교체 | 문항에 다시 이어 붙임 |
| 이미 있는 회차, 버전이 더 낮음 | 건너뜀 | 그대로 |
| 이미 있는 회차, 같은 버전인데 내용이 다름 | 바꿀지 물어봄 | 문항에 다시 이어 붙임 |

- 회차는 팩 안의 `종목코드-연도-회차`(예: `SURVEY-2022-1`)로 구별합니다. 파일 이름을 바꿔도, 메신저가 이름 뒤에 `(1)`을 붙여도 결과는 같습니다.
- 여러 회차를 한 번에 골라도 됩니다. 이미 있는 회차는 알아서 건너뜁니다.
- 다른 자격종목(예: 토목기사) 팩을 넣으면 홈 위에 **자격종목 드롭다운**이 생기고 종목별로 따로 학습합니다.

## 백업·복원

**백업 파일에는 학습 기록만 들어 있습니다. 문제팩은 들어 있지 않습니다.**

- 학습 기록 = 풀이 기록(고른 답·맞힘·모름·자신 없이 맞힘·풀이 시간), 메모, 회독 진행. 수백 KB 수준입니다.
- 문제팩(회차당 약 2.5MB)은 사내 게시판에서 언제든 다시 받을 수 있으므로 넣지 않습니다.
- **종목이 여러 개여도 백업 파일은 하나**입니다. 모든 종목·모든 회차의 기록이 한 파일에 들어갑니다. 따로 고를 필요가 없습니다.
- 복원은 기존 기록에 **합치기**입니다. 같은 기록은 한 번만 들어가므로 같은 백업을 두 번 복원해도 늘지 않습니다.
- 복원할 때 그 회차 문제팩이 기기에 있으면 바로 이어지고, 없으면 "매핑 대기"로 보관됩니다. 나중에 그 팩을 가져오면 자동으로 이어집니다. 복원과 팩 가져오기는 어느 쪽을 먼저 해도 됩니다.
- 복원 후 설정 화면의 **기록 지문**(예: `풀이 220건 · 메모 0건 · 지문 f94a3584`)이 백업할 때와 같으면 100% 복원된 것입니다.

### 휴대폰을 바꿀 때

1. 옛 휴대폰: 설정 → 백업 파일 저장 → 파일을 새 휴대폰으로 보냄(메신저 나에게 보내기·드라이브)
2. 새 휴대폰: 앱 설치 → 게시판에서 공부하던 종목의 문제팩 받아 가져오기 → 설정 → 백업 파일에서 복원

## 지우기 (v0.7 — 설정 → 이 기기 데이터 지우기 한 곳에서)

| 기능 | 고르는 것 | 지워지는 것 | 쓰는 때 |
|---|---|---|---|
| 학습 기록만 지우기 | 자격종목(또는 모든 종목) | 그 종목의 풀이 기록·메모·학습 묶음. 문제팩·학습 계획은 그대로 | 그 종목을 처음부터 다시 공부, 복원 시험 |
| 문제팩 지우기 | 자격종목 → 문제팩 전체/일부 | 고른 문제팩 + **그 문제팩 문항의 학습 기록** | 공간 정리, 필요 없는 회차 정리 |
| 문제팩 지우기 · 전체 선택 | 자격종목 → 전체 선택 | 그 종목의 문제팩 전부 + 학습 기록 + 학습 계획(= 종목 삭제) | 합격 등으로 더 공부하지 않을 때 |
| 문제팩 지우기 · 모든 종목 | 모든 종목(이 기기 전체) | 모든 문제팩·학습 기록·설정 | 휴대폰을 넘길 때 |

- **자격종목 관리**의 "종목 삭제"는 위 문제팩 지우기를 그 종목 **전체 선택**으로 엽니다(지워지는 것은 같음).
- 문제팩 목록(설정)과 팩 상세는 현황 보기만 합니다. 개별 삭제 단추는 없앴습니다.
- Android에서는 홈 화면의 앱 아이콘을 지워도 데이터가 Chrome에 남습니다. 다시 설치하면 그대로 보입니다.

## 저장공간 (설정 → 저장공간)

- **어디에 저장되나**: 문제팩·학습 기록은 휴대폰 **Chrome 앱의 내부 저장소**(이 앱 주소 전용 데이터베이스, IndexedDB)에 들어갑니다. 파일 관리자·갤러리에서는 보이지 않고, Android 설정 → 애플리케이션 → Chrome → 저장공간의 "데이터"에 포함됩니다.
- **사용 82.2MB / 한도 10.1GB**: 사용은 이 앱이 쓰는 양(측량 31회차 + 토목 1회차 문제팩 약 80MB + 학습 기록). 한도는 Chrome이 이 앱에 허락하는 최대치로, Chrome은 사이트 하나에 기기 전체 용량의 최대 약 60%까지 허락하되 실제 남은 공간에 따라 달라집니다. 회차당 약 2.5MB라 종목 몇 개를 넣어도 한도에 한참 못 미칩니다.
- **영구 저장: 허용됨**: 휴대폰 공간이 모자랄 때 Chrome은 오래 안 쓴 사이트의 데이터부터 스스로 지우는데, 영구 저장이 허용된 앱은 **그 자동 삭제에서 빠진다**는 뜻입니다. 단 사용자가 직접 지우는 것(Chrome 인터넷 사용 기록 삭제의 "사이트 데이터", 앱 정보 → 저장공간 지우기, Chrome 삭제)은 막지 못하므로 백업은 계속 필요합니다.
- **한도를 넘거나 휴대폰 공간이 꽉 차면**: 새 문제팩 가져오기·풀이 저장이 실패하고 오류 안내가 나옵니다(이미 저장된 기록은 그대로). 이때는 ① 합격한 종목이나 필요 없는 회차를 **문제팩 지우기**로 정리하거나 ② 휴대폰의 사진·앱 등을 정리해 공간을 비운 뒤 다시 시도합니다. 정리 전에 백업 파일을 저장해 두세요.

## 성적

- 점수 = 맞힌 문항 ÷ 과목 전체 문항 × 100. 다 풀기 전에는 안 푼 문항을 0점으로 계산합니다(20문항 중 2문항 정답 → 10점).
- 평균 = 과목 점수의 평균. 합격선 판정(과락 40점, 평균 60점)은 회차 100문항을 다 풀었을 때 보여 줍니다.
- 같은 회차를 다시 풀면(새 회독) 회독별 점수가 이력으로 남습니다.
