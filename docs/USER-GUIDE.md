# 원큐합격 사용 안내 (초안, v0.10.1)

8단계 출품 때 설치 가이드 1장으로 다듬는다. 실기기 시험에서 나온 질문을 여기에 모은다.

## 설치 (v0.10.1 — 첫 화면이 기기에 맞춰 안내)

앱 주소를 카카오톡·메일·게시판으로 받아 누르면 첫 화면에 그 기기에 맞는 설치 안내가 나옵니다. 설치 파일은 따로 없습니다(주소에서 바로 설치).

| 기기 | 권장 | 순서 |
|---|---|---|
| 안드로이드 휴대폰·태블릿 | Chrome | [원큐합격 앱 설치] 단추 → 설치. 단추가 없으면 ⋮ → 「앱 설치」 또는 「설치 및 바로가기 만들기」 → 「설치」. **앱 목록**에 원큐합격이 생기며, 홈 화면에 없으면 앱 목록에서 아이콘을 길게 눌러 「홈 화면에 추가」 |
| 아이폰·아이패드 | Safari | 공유(□↑) → 「홈 화면에 추가」 → 「추가」 → 홈 화면 아이콘으로 열기(Safari 화면과 기록이 따로) |
| PC | Chrome·Edge | 설치는 선택. 주소창 설치 아이콘 또는 [PC에 설치]. 같은 브라우저·프로필로 열어야 기록이 이어짐 |

- 카카오톡·네이버 앱 안에서 열리면 설치가 안 되고 기록도 따로 저장됩니다. 카카오톡은 바깥 브라우저로 자동으로 넘어가고, 안 되면 첫 화면의 [Chrome으로 열기]/[Safari로 열기] 또는 메뉴의 「다른 브라우저로 열기」.
- 안드로이드에서 「설치」는 앱 목록에 앱으로 설치, 「바로가기」는 홈 화면 링크입니다. **설치**를 고르세요.

## 학습 방법

- 홈: **시험일 | D-day**, **현재 점수 | 시험일 예상 점수**, **오늘 학습 목표**(오른쪽에 계획한 시간·문항), 그 아래 **모의고사**.
- **시스템 추천 학습**: 누르면 오늘 무엇을 풀지(오늘 틀린·모름 다시, 지난번 틀린·모름, 맞혔지만 다시 볼 문항, 새 문항)와 이유가 먼저 나오고, **학습 시작**을 누르면 앱이 골라 냅니다.
  틀린 문항이 쌓여도 새 문항을 계속 풀 수 있게 **복습은 한 번에 최대 60%**까지만 내고, 맞힌 문항도 찍어서 맞혔을 수 있으니 가끔 다시 냅니다. 다 풀면 틀린·모름 문항이 바로 한 번 더.
- **과목별 학습**: 과목마다 현재 점수 → 시험일 예상 점수, 풀이 횟수·마지막 날짜. **학습하기**를 누르면 그 과목의 복습 + 새 문항.
  진도율(풀어 본 비율)은 쓰지 않고 점수로 보여 줍니다.
- **오늘 학습 마치기**: 오늘 푼 결과와 점수.
- 같은 문항이 여러 회차에 나왔으면 문항 오른쪽 위에 **"n회 출제"**.
- 풀이 화면 아래 **모름 | 쉬움**(v0.9.2): 보기를 고르거나, 모르면 **모름**, 너무 쉬워 다시 볼 필요가 없으면 **쉬움**(보기 없이 정답 처리 → 다음 복습이 2주쯤 뒤로, 계속 쉬우면 몇 달 간격). 정답 화면에서 사실 몰랐으면 **모름으로 바꾸기**. 모의고사에는 쉬움이 없습니다.
- **웹검색**은 답한 뒤 정답·오답 화면에만 있습니다(v0.9.2 — 검색해서 맞힌 기록이 성적을 부풀리지 않게). 문항의 핵심 낱말로 **구글 AI 모드**가 새 탭에 열려 개념을 설명해 줍니다.
- 답한 뒤 **메모 쓰기**: 개념·풀이 요령을 적어 두면, 그 문항(다른 회차의 같은 문항 포함)을 다시 풀 때 위에 **메모 있음**(보라색)이 보이고 답한 뒤 메모가 나옵니다.
- **계산기·메모**(v0.10): 풀이 화면 아래 [계산기] [메모]. 계산 문제면 저절로 열립니다(설정 → 풀이 화면에서 끌 수 있음). 같은 문항에서는 계산기와 메모를 오가도 내용이 그대로입니다(v0.10.1).
  - 계산기: 사칙·괄호·거듭제곱·√·삼각함수(DEG/RAD)와 역함수·log·ln·π·×10ⁿ·Ans, **도·분·초**(°′″ 키를 숫자 뒤에서 누를 때마다 ° → ′ → ″, SHIFT+°′″ = 결과를 도분초로), SHIFT로 Pol(x,y)·Rec(r,θ)·쉼표
  - 메모: 손가락·펜으로 계산 과정을 적는 연습장. 펜을 쓰면 손바닥 터치는 무시. 다음 문항으로 넘어가면 지워집니다
- **태블릿 가로·PC**(폭 900px 이상): 왼쪽 문제 그림, 오른쪽 해설·계산 도구·보기 두 단. PC 키보드: 1~4 보기, M 모름, E 쉬움, Enter 다음, ← 이전
- 여러 종목이면 홈 위 **자격종목** 드롭다운에서 고릅니다.
- **오늘 학습 목표**를 채우면 풀이 화면에 "오늘 학습 목표 달성"과 오늘 결과(푼 문항·정답·오답·모름·성적)가 나옵니다. **오답/모름 n문항 다시 풀기** 또는 **계속 학습하기**를 고르면 오늘 기록을 바탕으로 이어서 추천하고, 과목별 학습 중이었다면 그 과목을 이어 갑니다.
- 풀이 중 ✕를 누르면 **나중에 이어서 하기 / 오늘 학습 마치기**를 고릅니다. 마치면 푼 기록은 그대로 남고, 홈은 "이어서 학습" 대신 **시스템 추천 학습**으로 바뀝니다.
- 과목별 학습의 막대는 **현재 점수**(과락선 미만 빨강 · 60점 미만 노랑 · 60점 이상 초록), 굵은 세로 실선은 **시험일 예상 점수**, 점선은 과락선입니다.
- 시스템 추천 학습·과목별 학습 모두 **오늘 남은 목표 문항 수**를 한 묶음으로 냅니다(목표를 채운 뒤에는 15문항씩).
- 묶음을 마치고 계속하면 먼저 **다시 풀기**(주황 띠): 방금 틀리거나 모른 문항만 한 번 더 풉니다.
- 확인 창(모의고사 제출·지우기 등)은 앱 안의 큰 글자 창으로 뜹니다.
- 문제팩 가져오기는 **설정**에서, 지우기는 **설정 → 이 기기 데이터 지우기**에서 합니다.

## 예상 점수·학습 원리 (v0.8, ADR 014 — 합격 가능성은 v0.8.1에서 화면에서 뺌)

- 홈 **시험일 예상 점수**는 색으로 봅니다: 60점 미만 빨강 · 75점 미만 주황 · 75점 이상 초록(v0.8.1).
- 학습 계획은 홈 시험일 아래 **학습계획 설정(재설정)** 한 곳에서만 바꿉니다.
- **계산 보기**: 핵심(예상 점수와 최고 점수) → 실제 시험 출제 유형(같은·변형·신규 막대) → 과목별 기출문항·신규문항·시험예상 점수(평균 줄 = 홈 점수) → 산식과 계산 근거(근거 수준·가정값 오차 범위) → 자주 묻는 질문.
- **학습 점검** 카드: 계획대로 해도(또는 최근 실제 학습량 그대로면) 합격이 어렵거나 아슬아슬할 때, 또는 최근 공부량이 계획의 90% 미만일 때만 뜹니다. "최근 n일 하루 평균 ○분(계획의 ○%) — 이 속도면 시험일 예상 ○점", "여유 있게 합격하려면 평소 하루 ○분(최소 ○분)". 실제 학습량은 어제까지 최근 14일(기록 3일 이상), 문항당 최대 5분, 모의고사 제외.
- **시스템 추천 학습** 화면: "오늘 계획 ○분 ÷ 문항당 ○초 = ○문항(− 오늘 푼 수)", 과목별 복습·새 문항 수, "왜 이렇게 구성했나요?"(복습 최대 60%, FSRS 복습 날짜, 새 문항 과목 배분, 섞지 않는 이유).
- 처음 며칠은 모든 과목을 10문항씩 번갈아 풀어 실력을 진단합니다. 그 뒤 새 문항은 과락 위험이 큰 과목에 많이, 다른 과목에도 조금씩 나눕니다. 시험 직전 3일은 복습을 "시험일에 가장 많이 잊었을 문항" 순으로(총정리).
- 홈 맨 아래 **학습 원리 · 예상 점수 계산 방법**: 앱이 따르는 학습 원리(인출 연습·피드백·간격 반복·FSRS·약한 과목 먼저·기출 중심)와 근거 논문, 가상 학습자 검증 결과, 한계.

## 학습 계획과 점수

- 홈 시험일 아래 **학습계획 설정(재설정)**에서 시험일·하루 학습시간·일주일에 공부하는 날을 정합니다. 평소와 다른 날(휴가·시험 직전 집중)은 **날짜별 학습시간**에 적습니다.
- **현재 점수** = 지금까지 답한 그대로(안 푼 문항·모름·오답 0점).
- **시험일 예상 점수**(v0.7, ADR 013) = 계획대로 공부하고 실제 시험을 봤을 때. 실제 시험 문항을 셋으로 나눠 계산합니다.
  - **같은 기출**: 가지고 있는 기출과 거의 같은 문항 → 그 기출을 익힌 만큼 맞힘
  - **변형 기출**: 숫자·표현만 바꾼 같은 개념 → 원래 기출을 익혔으면 대부분 맞힘
  - **처음 보는 문항**: 과목별 최근 첫 풀이 정답률(모름은 찍기 25%, 쉬움은 정답으로) + 기출을 많이 익힐수록 조금 오름
  - 비율은 가진 기출에서 직접 잽니다(측량 31회차: 같은 약 32% · 변형 약 23% · 처음 약 45%). 기출 회차가 적으면 비율이 낮아져(2회차면 3% 안팎) 시간을 늘려도 점수가 거의 오르지 않습니다.
- 같은 개념의 변형 문항은 한 번 익히면 적은 노력으로 함께 익힌다고 보고, 과목은 낮은 과목부터 고르게 올린다고 봅니다(과락 방지).
- **시험 전 3일**의 학습시간은 이미 익힌 문항을 마지막으로 다시 보는 데 먼저 씁니다(시험일 기억률 상승). 학습 계획 화면에 "날짜별 학습시간 반영: +○시간 → +○점"으로 따로 보입니다.
- 풀이 기록이 없을 때는 처음 보는 문항을 모두 찍는다(25%)고 가정한 값입니다. 풀기 시작하면 내 정답률로 바뀝니다.

## 모의고사

- 가지고 있는 기출 전체에서 과목별 실제 문항 수만큼, 자주 나온 문항일수록 잘 뽑히게 출제합니다. 시험시간은 문항당 1분 30초(100문항 2시간 30분).
- **모의고사 성적은 모의고사 이력에만** 남고 현재 점수·시험일 예상·학습 추천에는 넣지 않습니다.
- 풀이 중에는 정답을 보여 주지 않습니다. **제출**하거나 시간이 끝나면 채점하고(안 푼 문항 0점), 성적은 모의고사 탭에 쌓입니다.
- ✕를 누르면 **멈추고 나중에 이어서 풀기 / 지금 제출하고 채점 / 계속 풀기**를 고릅니다. 멈추면 남은 시간이 멈추고, 모의고사 탭에서 이어서 열면 그때부터 다시 흐릅니다(앱을 강제로 닫으면 계속 흐름).

## 문제팩

**같은 팩인지는 파일 이름이 아니라 팩 안의 내용으로 판단합니다.**

| 가져온 팩 | 앱의 동작 | 학습 기록 |
|---|---|---|
| 처음 보는 회차(종목·연도·회차가 다름) | 추가 | 회차별로 따로 쌓임 |
| 이미 있는 회차, 내용까지 똑같음 | 건너뜀("같은 팩 N개는 건너뜀") | 그대로 |
| 이미 있는 회차, 버전이 더 높음(다시 전처리한 팩) | 새 팩으로 교체 | 문항에 다시 이어 붙임 |
| 이미 있는 회차, 버전이 더 낮음 | 건너뜀 | 그대로 |
| 이미 있는 회차, 같은 버전인데 내용이 다름 | 바꿀지 물어봄 | 문항에 다시 이어 붙임 |

- 회차는 팩 안의 `종목코드-연도-회차`(예: `SURVEY-2022-1`)로 구별합니다. 파일 이름을 바꿔도, 메신저가 이름 뒤에 `(1)`을 붙여도 결과는 같습니다.
- 여러 회차를 한 번에 골라도 됩니다. 이미 있는 회차는 알아서 건너뜁니다.
- 다른 자격종목(예: 토목기사) 팩을 넣으면 홈 위에 **자격종목 드롭다운**이 생기고 종목별로 따로 학습합니다.
- 받은 문제팩 파일(zip)은 PC·구글 드라이브·휴대폰 저장소 중 한 곳에 보관해 두세요. 기기를 바꾸거나 다른 기기에서 공부할 때 다시 가져옵니다.

## 백업·복원

**백업 파일에는 학습 기록만 들어 있습니다. 문제팩은 들어 있지 않습니다.**

- 학습 기록 = 풀이 기록(고른 답·맞힘·모름·쉬움·풀이 시간), 메모, 학습 계획, 학습 묶음. 수백 KB 수준입니다.
- 문제팩(회차당 약 2.5MB)은 보관해 둔 zip 파일로 언제든 다시 가져올 수 있으므로 넣지 않습니다.
- **종목이 여러 개여도 백업 파일은 하나**입니다. 모든 종목·모든 회차의 기록이 한 파일에 들어갑니다.
- 복원은 기존 기록에 **합치기**입니다. 같은 기록은 한 번만 들어가므로 같은 백업을 두 번 복원해도 늘지 않습니다.
- 복원할 때 그 회차 문제팩이 기기에 있으면 바로 이어지고, 없으면 "매핑 대기"로 보관됩니다. 나중에 그 팩을 가져오면 자동으로 이어집니다. 복원과 팩 가져오기는 어느 쪽을 먼저 해도 됩니다.
- 복원 후 설정 화면의 **기록 지문**(예: `풀이 220건 · 메모 0건 · 지문 f94a3584`)이 백업할 때와 같으면 100% 복원된 것입니다.

### 다른 기기(태블릿·PC)와 이어서 공부하기 (v0.9.2)

서버 없이 기기 안에만 저장하는 앱이라 자동 동기화는 없습니다. 백업 파일을 주고받아 **합칩니다**.

1. 두 기기 모두 앱을 설치하고 같은 문제팩(zip — PC·구글 드라이브·휴대폰 저장소에 보관한 파일)을 가져옵니다.
2. 공부를 마친 기기: 휴대폰·태블릿은 **공유로 보내기** → 메일·텔레그램·구글 드라이브. 카카오톡은 공유로 파일이 붙지 않으므로 **백업 파일 저장** 후 채팅방 + → 파일에서 다운로드 폴더의 백업 파일을 보냅니다. PC는 **백업 파일 저장** 후 파일을 메일·텔레그램·카카오톡 PC 창에 끌어다 놓습니다.
3. 이어서 공부할 기기: 설정 → **백업 파일에서 복원(합치기)**. 같은 풀이는 한 번만 들어가고, **학습 계획은 더 최근에 바꾼 쪽**으로 맞춰집니다(마지막 백업 시각·고른 종목 같은 기기별 값은 그대로).
4. 기기를 바꿀 때마다 한 번씩 보내면 두 기기 기록이 같아집니다.

### 휴대폰을 바꿀 때

1. 옛 휴대폰: 설정 → 백업 파일 저장 → 파일을 새 휴대폰으로 보냄(메일·텔레그램·구글 드라이브, 또는 카카오톡 채팅방 + → 파일)
2. 새 휴대폰: 앱 설치 → 보관해 둔 문제팩 가져오기 → 설정 → 백업 파일에서 복원

## 지우기 (v0.7 — 설정 → 이 기기 데이터 지우기 한 곳에서)

| 기능 | 고르는 것 | 지워지는 것 | 쓰는 때 |
|---|---|---|---|
| 학습 기록만 지우기 | 자격종목(또는 모든 종목) | 그 종목의 풀이 기록·메모·학습 묶음. 문제팩·학습 계획은 그대로 | 그 종목을 처음부터 다시 공부, 복원 시험 |
| 문제팩 지우기 | 자격종목 → 문제팩 전체/일부 | 고른 문제팩 + **그 문제팩 문항의 학습 기록** | 공간 정리, 필요 없는 회차 정리 |
| 문제팩 지우기 · 전체 선택 | 자격종목 → 전체 선택 | 그 종목의 문제팩 전부 + 학습 기록 + 학습 계획(= 종목 삭제) | 합격 등으로 더 공부하지 않을 때 |
| 문제팩 지우기 · 모든 종목 | 모든 종목(이 기기 전체) | 모든 문제팩·학습 기록·설정 | 휴대폰을 넘길 때 |

- **자격종목 관리**의 "종목 삭제"는 위 문제팩 지우기를 그 종목 **전체 선택**으로 엽니다(지워지는 것은 같음).
- 문제팩 목록(설정)과 팩 상세는 현황 보기만 합니다. 개별 삭제 단추는 없앴습니다.
- Android에서는 원큐합격 아이콘을 지워도 데이터가 Chrome에 남습니다. 다시 설치하면 그대로 보입니다.

## 저장 위치와 저장공간 (설정 → 내 학습 기록 지키기, v0.9.2·v0.10.1)

설정 맨 위 카드가 지금 기기에 맞춰 **저장 위치 · 이럴 때 지워집니다 · 지키는 방법**과 영구 저장·마지막 백업 상태를 보여 줍니다.

- **평소**: 일주일에 한 번쯤 [백업 파일 저장] — 기기의 「다운로드」 폴더(아이폰은 파일 앱 › 다운로드)에 저장되어 브라우저 기록을 지워도 남습니다.
- **기기를 바꾸거나 초기화할 때만** 백업 파일을 PC·구글 드라이브·메일로 옮깁니다. 문제팩 zip도 한 곳에 보관해 두면 다시 가져올 때 기록이 이어집니다.

| 기기 | 저장 위치(화면 표시) | 지워지는 때 |
|---|---|---|
| Android(Chrome·삼성 인터넷) | 이 휴대폰의 Chrome 앱 안(설치한 앱도 같은 곳). 파일 관리자에는 안 보임 | 인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터(영구 저장이어도), Chrome 앱 데이터 삭제, 기기 초기화 |
| 아이폰·아이패드 홈 화면 앱 | 이 아이폰의 원큐합격 앱 안(Safari와 별도) | 홈 화면에서 앱 아이콘 삭제, Safari 웹 사이트 데이터 삭제(함께 지워질 수 있음), 기기 초기화 |
| 아이폰·아이패드 Safari 화면 | 이 아이폰의 Safari 안(홈 화면 앱과 별도) | 웹 사이트 데이터 삭제, **7일 넘게 안 쓰면 Safari가 지울 수 있음** → 홈 화면에 추가해서 쓰세요 |
| PC(Chrome·Edge·웨일) | 이 PC의 브라우저 안(지금 쓰는 사용자 프로필) | 인터넷 사용 기록 삭제(사이트 데이터), 다른 브라우저·프로필·시크릿 창에서는 안 보임 |

- 아이폰 홈 화면 앱은 Safari의 7일 규칙을 받지 않습니다(WebKit). 아이콘 삭제 시 데이터 삭제 여부는 실기기로 확인 중(device-tests Y2).
- **사용 82.2MB / 한도 10.1GB**: 사용은 이 앱이 쓰는 양(측량 31회차 + 토목 1회차 문제팩 약 80MB + 학습 기록). 한도는 브라우저가 이 앱에 허락하는 최대치로, 기기 전체 용량의 최대 약 60%까지 허락하되 실제 남은 공간에 따라 달라집니다. 회차당 약 2.5MB라 종목 몇 개를 넣어도 한도에 한참 못 미칩니다.
- **영구 저장: 허용됨**: 기기 공간이 모자랄 때 브라우저(Chrome·Safari 17 이상)는 오래 안 쓴 사이트의 데이터부터 스스로 지우는데, 영구 저장이 허용된 앱은 **그 자동 삭제에서 빠진다**는 뜻입니다. 단 사용자가 직접 지우는 것(인터넷 사용 기록 삭제의 "사이트 데이터", 앱 정보 → 저장공간 지우기, 브라우저 삭제)은 막지 못하므로 백업은 계속 필요합니다.
- **한도를 넘거나 기기 공간이 꽉 차면**: 새 문제팩 가져오기·풀이 저장이 실패하고 오류 안내가 나옵니다(이미 저장된 기록은 그대로). 이때는 ① 합격한 종목이나 필요 없는 회차를 **문제팩 지우기**로 정리하거나 ② 기기의 사진·앱 등을 정리해 공간을 비운 뒤 다시 시도합니다. 정리 전에 백업 파일을 저장해 두세요.

## 성적

- 점수 = 맞힌 문항 ÷ 과목 전체 문항 × 100. 다 풀기 전에는 안 푼 문항을 0점으로 계산합니다(20문항 중 2문항 정답 → 10점).
- 평균 = 과목 점수의 평균. 합격선 판정(과락 40점, 평균 60점)은 회차 100문항을 다 풀었을 때 보여 줍니다.
