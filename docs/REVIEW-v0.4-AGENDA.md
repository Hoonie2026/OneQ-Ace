## 1. 지금의 전체 흐름 (v0.4.0 그대로)

```
[사용자] 기출 PDF 확보(comcbt 교사용·형광펜형·스캔본, 2022-2 이후 CBT 기출은 비공개)
   ↓
[전처리기 PC 창] ① 종목 검색 → 출제기준 프로필(standards/*.json 4종 내장 + 사용자 직접 입력, %APPDATA%)
   ↓            ② 팩 정보(만든 사람·저장 폴더·처리 속도)
   ↓            ③ PDF 넣기 → 파일명에서 시행일·회차 추정 · 과목 개편 요약 미리 보기
   ↓
[추출] extract.py — 텍스트 PDF 배치 분석(pdfplumber): 문항 경계·보기 번호(배치 판정)·정답(보기 표시/정답표)
       스캔본은 Tesseract OCR(선택 설치, 실제 스캔본 검증 안 됨)
   ↓
[준비] pack.prepare — 과목 별칭 통합·구기준 문항별 재배정 제안(글자 2-gram)·법령·기준 표시(낱말 사전, 건설안전 15%)·경고
   ↓
[검수] 경고 회차 두 번 눌러 검수 창 → 정답·과목·제외 → 저장하고 그 회차 다시 만들기
   ↓
[팩] 회차마다 oqp/1 zip 1개(문항 = 잘라 낸 이미지 + 메타, packVersion 2)
   ↓
[옮기기] zip 수십 개를 드라이브 등으로 폰·태블릿에 → 앱 [문제팩 가져오기]
         (30여 개면 기기가 다 받을 때까지 수 분~십여 분 무반응 — v0.10.8에서 안내로 완화, 전처리기는 아직 묶음 파일을 안 만듦)
   ↓
[앱 PWA] 가져오기 → 학습 엔진(FSRS·시험 구성·예상 점수) → 풀이·복습·모의고사
```

## 2. 전처리기 — 근본 재검토 질문

| # | 질문 | 지금 v0.4.0 | 넓혀 볼 선택지 |
|---|---|---|---|
| W1 | **누가 전처리하나?** | 동료 각자 PC에서 exe로 | 한 사람(관리자)이 만들어 팩만 배포 / 각자 / 섞기 — 기출 PDF·팩 배포 권리도 함께 확인 |
| W2 | **어디서 돌리나?** | Windows exe(PySide6, PyInstaller 폴더형) — 백신·서명·동료 PC 실측 안 됨 | 앱(PWA) 안에서 PDF 처리(pdf.js·WASM, 설치·옮기기 단계 없음) / 웹 전처리 페이지 / exe 유지 |
| W3 | **팩 단위** | 회차 1개 = zip 1개 | 종목 하나 묶음(앱 v0.10.8은 읽음) / 증분 갱신 / 앱에서 직접 내려받기 |

## 3. 큐넷 공식 OpenAPI (2026-10-21 확인 — 이전 "공개 API 없음" 정정)

큐넷이 직접 운영하는 `openapi.q-net.or.kr`이 공공데이터포털을 통해 무료(자동 승인, 인증키 필요)로 열려 있다.

| API | 주요 응답 | 쓸 곳 |
|---|---|---|
| 국가자격 시험교시 과목 정보 `InquiryExamKmInfo/getList?jmCd=` | 과목명 kmNm · 문항수 qitemCnt · 교시 · 시험시간 · 세부유형 | 프로필 없는 종목의 과목 자동 채우기 |
| 국가자격 종목 목록 정보 `InquiryListNationalQualifcationSVC/getList` | 종목코드 jmcd · 종목명 · 계열 · 직무분야 | 종목 목록(CSV 대신) |
| 국가자격 종목별 자격정보 `InquiryInformationTradeNTQSVC/getList?jmCd=` | 정보구분 + 본문(출제경향·시험과목·합격기준 글) | 참고 표시 |
| 국가기술자격시험 출제기준 및 문제정보(파일, PDF, 2026-09-15 갱신) | 종목별 출제기준 원문 | 3단계(세부항목) |

- 한계: 옛 과목명·신구 대응·세부항목·적용 기간은 없음 / 필기·실기 구분 방식은 실제 응답으로 확인 필요
- 인증키를 배포 exe에 넣지 않는 쪽 권장(개인 계정·호출 한도 공유) → "빌드 때 받아 내장" + "선택: 자기 키로 최신 받기"
- **대기 중**: 사용자가 PC에서 `km-1380.xml`·`qual-list.xml` 받아 첨부(클라우드에서는 큐넷 서버 접속 차단)
