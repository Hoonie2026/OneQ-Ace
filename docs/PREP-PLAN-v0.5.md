# 전처리기 v0.5 개발 계획 (2026-10-23, 세션 #11)

- **결정 내용은 ADR 021**(1~7절), PC가 필요한 일은 **`docs/PC-TODO.md`**(P0~P16, P13·P15는 취소). 이 문서는 순서와 남은 질문만 — 결정을 여기 다시 쓰지 않는다(어긋남 방지)
- 앞 문서와의 관계: `REVIEW-v0.4-AGENDA.md`(질문 목록) → ADR 021 5절에서 처리. `PREP-PLAN-v0.4.md`의 공공데이터 CSV·큐넷 OpenAPI·출제기준 PDF 읽기 부분은 폐기

## 1. 목표 흐름 (v0.5)

```
[배포] 앱 주소 하나(Pages): PC → [전처리기 받기]·[이 PC에 학습앱 설치] / 폰 → 앱 설치   (ADR 021 7절)

[직원 PC] 전처리기 실행 → 스위치보드(입력 칸 없음, 첫 화면에 "폰에 앱 설치" QR)
  ① 종목 검색(별칭 허용) ─┬─ 큐넷 출제기준 자료실: 현행 출제기준 HWP → 과목·주요/세부/세세항목
                         └─ comcbt 종목 게시판: 기출 목록(시행일·회차) → 회차 범위 골라 받기
     comcbt에 없음/부족 → 직접 올리기(조건 셋, 샘플 이미지, 즉시 검사)            (1·3절)
  ② PDF 처리: 한 목록 · 페이지별 글자/OCR · 파일마다 진행 막대 · 끝난 파일 누르면 결과 화면
     → 종목·시행일·회차·과목을 내용에서(없으면 "0000년 nn회")
     → 의심 문항만 검수(필수 정보) · 못 정한 단원·유형만 몰아 고르기(선택)       (2·6절)
  ③ 팩을 기본 폴더에 저장하고 폴더를 보여 줌 → 옮기기는 사용자가 직접           (7절)
[앱] 과목별 학습 = 단원별 / 유형별(계산·기준법령·개념실무 + 필터 셋), 묶음 뒤 "섞어 풀기" 안내 (4절)
```

## 2. 단계와 순서 (☁ = 클라우드에서 지금 가능, 🖥 = PC-TODO 번호)

| A2 ☁ | comcbt 메뉴·게시판·게시글 파서, 큐넷 자료실 파서 + 시험(저장한 HTML로) | 🖥P1·P2 표본 HTML |
| A3 ☁ | 수집 화면(스위치보드: 검색 → 출제기준·기출 목록 → 범위 → 받기), 직접 올리기 안내·조건 검사 | A1·A2 |
| A4 🖥 | 실제 수집 시험 | 🖥P6 |
| B1 🖥→☁ | OCR 엔진 비교·결정 | 🖥P3·P4·P5 |

| B3 ☁ | 처리 화면: 한 목록·[글자]/[스캔] 표시·진행 막대와 단계·결과 화면·의심 문항 검수·건너뛰기(정답 모르는 문항 빼고 팩)·입력 칸 자동화·출처 자동 | B2, 기존 v0.4.0 화면 디자인 유지 |
