## 1. 목표 흐름 (v0.5)

```
[배포] 앱 주소 하나(Pages) → PC: 1단계 전처리기 설치(Setup.exe) → 전처리기 [학습앱 설치](PC·Android·iPhone) / 폰: 받은 팩 바로 넣기   (ADR 021 7절)

[직원 PC] 전처리기
  ① 자격종목명 → [조회] → 큐넷 현행 출제기준(보기 창 PDF) → 과목·문항 수·주요/세부/세세항목. 못 받으면 직접 올리기 상자 (1절)
  ② 기출 PDF: [comcbt 최근 기출 받기](게시판 첫 쪽만) + 이전·최신 회차는 직접 올리기. 조건 셋 안내 (1·3절)
  ③ PDF 처리: 한 목록 · 글자/스캔(OCR, ADR 022) · 파일마다 진행 막대 · 끝난 파일 누르면 결과 화면
     → 종목·시행일·회차·출처를 내용에서(없으면 "0000년 nn회") → 의심 문항만 검수 · 단원은 확신 있는 것만, 나머지 미정 + 후보 3개 (2·4·6절)
  ④ 종목 묶음 1개 저장 → 옮기기는 사용자가 직접(소셜미디어·메신저·메일 공유) (7·8절)
[앱] 과목별 학습 = 단원별(+ 미정 칸, 답한 뒤 후보 3개에서 고름) / 유형별(계산·기준법령·개념실무 + 필터 셋) (4절)
```
