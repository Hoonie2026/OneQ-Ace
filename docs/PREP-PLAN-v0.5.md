## 1. 목표 흐름 (v0.5)

```
[직원 PC] 전처리기 설치·실행 → 스위치보드
  ① 종목 검색(별칭 허용) ─┬─ 큐넷 출제기준 자료실: 현행 출제기준 HWP → 과목·주요/세부/세세항목
                         └─ comcbt 종목 게시판: 기출 목록(시행일·회차) → 회차 범위 골라 받기
     comcbt에 없음/부족 → 직접 올리기(조건 셋, 샘플 이미지, 즉시 검사)
  ② PDF 처리 ─ 글자 또는 OCR(페이지별 자동) → 종목·시행일·회차·과목을 내용에서(없으면 "0000년 nn회")
              → 문항 자르기·정답(확신 낮은 것만 검수) → 단원(주요·세부항목)·유형 배정
              ※ 이 단계 세부는 사용자 설명 대기
  ③ 팩 → 기기로 옮기기 (W3/W4 미정)
[앱] 과목별 학습 = 단원별 / 유형별(계산·기준법령·개념실무 + 필터 셋), 묶음 뒤 "섞어 풀기" 안내
```

## 2-1. PDF 처리 단계 — 사용자 요구(2026-10-23)와 제안 (**검토 중, 결정 전**)

사용자 요구: 입력 두 길(수집·직접 올림) / 글자 PDF·이미지 PDF 구분 처리 / 파일마다 진행 막대, 끝난 파일을 누르면 결과 화면 / 끝나면 전처리기에서 바로 학습앱으로 / **검수는 앱이 의심한 것만** / 처리자 이름·출처 같은 학습에 불필요한 입력 없애기(comcbt 출처는 자동) — 사용자 개입은 "문제 분류·자동 처리 미흡"만 / 나중에 **전처리기·학습앱 통합 배포**

제안:
- 입력 하나의 목록: 수집분·올린 파일이 같은 목록에 섞임. 출처 자동(comcbt = 게시글 제목·주소, 올린 파일 = "직접 올림")
- 페이지별 판정(글자 수·깨진 글자 비율) → 파일 행에 [글자]/[스캔]/[섞임] 표시
- 진행 막대 + 지금 단계(읽기 → 문항 나누기 → 정답 → 분류 → 팩). 끝난 파일 누르면 결과 화면: 과목별 문항 수, 정답 상태, 유형 분포, 문항 미리 보기 몇 개, 의심 n건이면 [확인하기]
- 의심 기준(이것만 검수): 정답 못 찾음 / 보기 표시와 정답표가 다름 / 보기 수 이상 / 과목 문항 수가 출제기준과 다름(누락·경계 오류) / OCR 확신 낮음 / 정답 표시 지움 잔존 / 구기준 과목 재배정 확신 낮음. 시행일 자동 지정은 알림만
- 검수 화면: 의심 문항만 차례로, 문항 그림 + 원본 쪽 + 고를 것 하나(정답 1~4 / 빼기). **검수를 건너뛰면 정답 모르는 문항은 빼고 팩을 만듦**
- 입력 없애기: v0.4.0의 만든 사람·저장 폴더·원본 출처·문제 종류·처리 속도 5칸 → 모두 자동(스키마 `preparedBy` 필수 → "원큐합격 전처리기 v0.5" 자동)
- **충돌 확인 필요**: 사용자 개입 항목의 "문제 분류" vs ADR 021 4.5 "분류는 검수 대상 아님" — 사용자 답 대기
