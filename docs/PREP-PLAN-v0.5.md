# 전처리기 v0.5 개발 계획 (2026-10-23, 세션 #11)

- **결정 내용은 ADR 021**, PC가 필요한 일은 **`docs/PC-TODO.md`**(P0~P12). 이 문서는 순서와 남은 질문만 — 결정을 여기 다시 쓰지 않는다(어긋남 방지)
- 앞 문서와의 관계: `REVIEW-v0.4-AGENDA.md`(질문 목록) → ADR 021 5절에서 W1~W13 처리. `PREP-PLAN-v0.4.md`의 공공데이터 CSV·큐넷 OpenAPI 부분은 폐기

## 1. 목표 흐름 (v0.5)

```
[직원 PC] 전처리기 설치·실행 → 스위치보드
  ① 종목 검색(별칭 허용) ─┬─ 큐넷 출제기준 자료실: 현행 출제기준 HWP → 과목·주요/세부/세세항목
                         └─ comcbt 종목 게시판: 기출 목록(시행일·회차) → 회차 범위 골라 받기
     comcbt에 없음/부족 → 직접 올리기(조건 셋, 샘플 이미지, 즉시 검사)
  ② PDF 처리 ─ 글자 또는 OCR(페이지별 자동) → 종목·시행일·회차·과목을 내용에서(없으면 "0000년 nn회")
              → 문항 자르기·정답(확신 낮은 것만 검수) → 단원(주요·세부항목)·유형 배정
              ※ 이 단계 세부는 사용자 설명 대기
  ③ 팩 → 기기로 옮기기 (W3/W4 미정)
[앱] 과목별 학습 = 단원별 / 유형별(계산·기준법령·개념실무 + 필터 셋), 묶음 뒤 "섞어 풀기" 안내
```

## 2. 단계와 순서 (☁ = 클라우드에서 지금 가능, 🖥 = PC-TODO 번호)

| 단계 | 일 | 전제 |
|---|---|---|
| A1 ☁ | 출제기준 HWP·HWPX 글자 읽기 모듈(외부 프로그램 없이), 표에서 과목·주요/세부/세세항목 뽑기 | 🖥P2 표본 HWP(없으면 공개 표본으로 먼저) |
| A2 ☁ | comcbt 메뉴·게시판·게시글 파서, 큐넷 자료실 파서 + 시험(저장한 HTML로) | 🖥P1·P2 표본 HTML |
| A3 ☁ | 수집 화면(스위치보드: 검색 → 출제기준·기출 목록 → 범위 → 받기), 직접 올리기 안내·조건 검사 | A1·A2 |
| A4 🖥 | 실제 수집 시험 | 🖥P6 |
| B1 🖥→☁ | OCR 엔진 비교·결정 | 🖥P3·P4·P5 |
| B2 ☁ | 내용에서 종목·시행일·회차 읽기, 없으면 "0000년 nn회" + 팩 스키마 "시행일 모름" + 앱 순서 처리 | (글자 PDF로 먼저 가능) |
| C1 ☁ | 단원(주요·세부항목) 배정, 유형 판정, 순서형 판정 + 확신도, 팩 선택 칸 | A1(출제기준 항목) |
| C2 🖥→☁ | 정확도 실측: 계산 = 토목 응용역학, 단원 = 측량 1과목, 법령 = 건설안전 1과목 | 🖥P7·P8, C1 |
| C3 ☁ | 앱: 단원별·유형별 화면, 계산·법령·절차 묶음, 법령 묶음 찾아보기, 빈출·내가 틀린 것 필터, "섞어 풀기" 안내 | C2 결과가 기준 이상일 때 |
| D 🖥 | 실행파일 빌드 실측, 실기기 확인 | 🖥P9·P11 |

PDF 처리 단계(②) 설명을 받으면 B·C 단계에 끼워 다시 정리한다.

## 3. 아직 정하지 않은 것
- PDF 처리 단계 세부(사용자 설명 대기)
- W3/W4 팩 단위·기기로 옮기는 길, W12 출품 "처음 5분"
- 부정형 발문 강조(선택)
- 분류 정확도 기준선(얼마 이상이면 화면에 내놓나) — C2 실측 전에 정함
- 틀린 분류 신고 길([이 문제 분류가 이상해요]) 만들지 여부
- 회사 PC에 한글이 깔려 있으면 HWP 기출 자동 변환을 덧붙일지(기본은 안내만)
