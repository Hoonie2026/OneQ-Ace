## 1. 목표 흐름 (v0.5)

```
[배포] 앱 주소 하나(Pages): PC → [전처리기 받기]·[이 PC에 학습앱 설치] / 폰 → 앱 설치   (ADR 021 7절)

[직원 PC] 전처리기 실행 → 스위치보드(입력 칸 없음, 첫 화면에 "폰에 앱 설치" QR)
  ① 종목 검색(별칭 허용) → 큐넷 출제기준 자료실: 현행 출제기준(보기 창 PDF) → 과목·문항 수·주요/세부/세세항목 (1절)
  ② 기출 PDF 올리기(사용자가 직접 구함 — 끌어다 놓기·파일/폴더 추가). 조건 셋 안내·샘플 이미지·즉시 검사 (1·3절)
  ③ PDF 처리: 한 목록 · 페이지별 글자/OCR · 파일마다 진행 막대 · 끝난 파일 누르면 결과 화면
     → 종목·시행일·회차·과목·출처를 내용에서(시행일 없으면 "0000년 nn회")
     → 의심 문항만 검수(필수 정보) · 단원은 확신 있는 것만 확정, 나머지는 미정 + 후보 3개 (2·4·6절)
  ④ 종목 묶음 1개를 기본 폴더에 저장하고 폴더를 보여 줌 → 옮기기는 사용자가 직접 (7·8절)
[앱] 과목별 학습 = 단원별(세부항목, 주요항목은 머리글, + 미정 칸 — 미정 문항은 답한 뒤 후보 3개에서 고름) / 유형별(계산·기준법령·개념실무 + 필터 셋), 묶음 뒤 "섞어 풀기" 안내 (4절)
```
