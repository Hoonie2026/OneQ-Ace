## 앱 — 7단계 실사용 기록으로 보정할 가정값

- 망각형 60일 예상 +8점(알려진 한계) — "시험일 예측 vs 모의고사·실제 점수" 대조, 필요하면 FSRS 매개변수 최적화(fsrs-rs wasm 등)
- 전이 크기 TRANSFER 0.3(Pan & Rickard 2018 근거, 가정) — 학습한 문항 수에 따른 첫 풀이 정답률 추세, 기록 100건 이상부터
- VARIANT_TRANSFER 0.7 · VARIANT_COST 1.7 · LATE_R 0.95 · 유사도 경계 0.6 — 군집 안 첫 풀이 정답률로
- 합격 기준 경고 투영 상수(R* 0.85, 신규 비용 2.5 + 1.5 × 오답 확률), 게이트의 예상 오차 MODEL_SD 4점
- 복습 상한 REVIEW_SHARE 60% — 밀린 복습이 며칠 이상 쌓이면 잠시 올릴지
- 시험 구성 비율을 최근 회차가 빠진 팩(2022-2 이후 CBT 비공개)에 맞게 — 보유 회차와 시험일 사이 간격 반영 여부
- 고정 시간형 14일 과락형(하루 60분)은 여전히 과락 — "과락 집중 모드"는 보류(ADR 007)

## 앱 — 성능·기기

- 엔진: 3,400문항·3,000건 Node 230ms, 학습 점검 이분 탐색 약 0.4초, 개념 군집 첫 계산 — 7단계 실기기 "홈 2초 이내" 실측 후 캐시·Web Worker 판단
- S11(저장공간 부족 경고) 실기기 확인 — 7단계 20회차 실측 때
- 팩 가져오기(ADR 017): 앱은 v0.10.8부터 묶음 파일을 읽음 — **전처리기에서 묶음 만들기**(창에 "묶음 파일도 만들기" 체크, `oneq-<종목>-bundle-<첫해>-<끝해>.zip`)는 사용자 결정 후
- iPhone 보조 확인(동료 기기, 7단계 전 필수) — iOS 상태표시줄 black-translucent → default 확인 포함
- 글자 단위 px → rem(기기 글꼴 크기 설정 반영) 검토

## 앱 — 기능 후보

- 기기 간 자동 동기화: 사용자 본인 Google 드라이브 앱 폴더(`drive.appdata`) — 사내망·보안 정책 확인 후(ADR 015 2절 B안, 지금은 백업 파일 맞추기)
- 계산 도구: 메모를 문항별로 저장할지(지금은 문항 넘기면 지움 — 사용자 결정), 휴대폰 세로에서 계산기 패널 높이 조절 손잡이. (계산 문제 자동 분류는 v0.10.4에서 하지 않기로 — ADR 015 9절)

- 풀이 화면: 문항 이미지 기본 배율 — 글자가 작다는 의견이 나오면 "글자 크기" 설정(7.4)을 기본 배율로
- 시험 2주 전부터 과목 섞기(연구: 후반 섞기·마지막 2주 시간 재는 모의고사) — `startToday` 코드 남겨 둠
- 실제 학습량 그대로면 예상(학습 점검)을 오늘 학습 마치기 요약에도 보여 줄지
- 웹검색 검색어 품질(수식 글꼴 PUA 문항은 낱말이 적음 — 토목 경향문제). v0.9.2부터 답한 뒤에만 열림
- 같은 개념 군집(변형 문항)의 메모도 보여 줄지
- e2e: 실제 팩이 없으면 대체 팩과 '다른 종목' 팩의 종목 코드(TEST)가 같아 종목 선택 단계에서 실패 — 대체 팩 코드 분리
