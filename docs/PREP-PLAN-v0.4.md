- **2026-10-23: 다음 계획은 `PREP-PLAN-v0.5.md`(ADR 021). 이 문서의 공공데이터 CSV·큐넷 OpenAPI 부분은 폐기. 출제기준 읽기는 큐넷 출제기준 자료실 검색 → 보기 창 PDF로(ADR 021 1절)**
- 상태: **1단계 완료(전처리기 v0.4.0, 2026-10-20)** — 결정은 ADR 019. 2단계(앱 v0.10.9 법령 안내: 답한 뒤 안내 + 찾아보기 — 사용자 선택)·3단계 남음

## 0. 프롬프트(안)과 현실 대조 요약

| 프롬프트(안) 요구 | 지금 앱 | 사실 확인 | 보완 방안 |
|---|---|---|---|
| ① 디자인 전면 개편, 글자 잘림·여백 | 기본 위젯 그대로(캡처) | 캡처로 확인: 묶음 제목이 테두리 선에 걸려 잘림, 표 머리 좁음, 빈 표에 안내 없음, 위아래 간격 불균일, 원큐합격 앱과 다른 모양 | **채택(전면)** — 1단계 |
| ② 드롭다운 폐기 → 자연어 종목 검색 + 큐넷 실시간 출제기준 수집 | 프로필 있는 3종목만 드롭다운 | 큐넷에 종목 검색·출제기준 **공개 API 없음**. 공공데이터포털: 종목 목록 CSV(613개, 로그인 없이 내려받기)·공통 편성기준 CSV(종목코드+종목명 630행)·공개문제 API. 출제기준은 큐넷 자료실의 PDF/HWP 첨부. 큐넷 화면은 자동 조회 시 같은 주소로 되돌려 보냄(세션 #9 확인) — 화면 긁기는 차단·구조 변경에 약함 | **부분 채택**: 내장 종목 목록 + 별칭 검색(오프라인 동작) + 출제기준 PDF로 프로필 만들기. 큐넷 화면 직접 읽기는 안 함 |
| ③ 신·구 과목 자동 대조·재배분, 폐지 문항 삭제, 신설 영역 결손 경고 | 과목명 별칭 통합(ADR 005·016), 구기준 회차 문항별 재배정 제안(측량 2011, 글자 2-gram) | **측량 예시는 틀림**: 측량및지형공간정보기사 현행 5과목(측지학 및 위성측위시스템·응용측량·사진측량 및 원격탐사·지리정보시스템·측량학), 적용 2025-01-01~2027-12-31 — "현행 4과목·스마트측량"은 확인되지 않음. 건설안전 예시는 맞음(이미 반영, ADR 016) | **채택(단계적)**: 과목 개편 요약 카드는 1단계, 세부항목 기반 재배정·결손 진단은 출제기준 PDF를 읽게 된 뒤(3단계). 자동 삭제는 하지 않고 검수 필터로 |
| ④ 법령·기준 개정 위험: 전처리기 사전 경고 + 정답 화면 경고 + 웹 검증 | 팩 포맷에 문항 `flags: law`·`lawRefs` 칸이 **이미 있으나 비어 있음**. 앱은 답한 뒤 [웹검색](구글 AI 모드) 있음 | 법령 개정으로 옛 정답이 틀릴 수 있다는 위험은 실제 있음. 다만 프롬프트의 개정 수치 예시(비계 간격 등)는 확인 전 — 앱 문구에 쓰지 않음. 2022-2 이후 기사 CBT 기출은 비공개라 "최근 5개년 CBT 기출 확보" 권고는 실행 불가 | **채택(수위 조정)**: 전처리기가 법령·기준 문항 자동 표시 + 요약 경고(1단계), 앱 정답 화면 안내 + 현행 기준 찾아보기(2단계). 앱이 웹 결과를 직접 요약하지는 않음(서버·외부 API 없음 원칙) |

## 1단계 (이번) — 전처리기 v0.4.0

### 1-1. 화면 전면 개편 (원큐합격 앱과 같은 디자인)
- **머리 띠**: 1Q 로고 + "원큐합격 전처리기" + "기출 PDF → 문제팩" + 버전. 앱과 같은 색(파랑 #1f5fd1, 노랑 #f2b830, 잉크 #1d2433)
- **글꼴**: Pretendard(SIL OFL — 함께 배포 가능, 앱과 같음) 내장, 없으면 맑은 고딕
- **카드 3장**(① 종목 ② 기출 PDF ③ 만들기): 둥근 모서리 12px, 옅은 테두리 #E2E8F0, 안쪽 여백 20px, 카드 사이 16px — 기본 묶음 상자(QGroupBox) 대신 → 제목이 선에 걸려 잘리는 문제 원천 제거
- **글자 크기 단계**: 제목 20 / 카드 제목 16 / 본문·입력 14 / 배지·보조 12 (px), 입력·단추 최소 높이 36·40px, 줄 간격 1.5
- **PDF 표**: 비었을 때 끌어다 놓기 안내 그림(점선 상자 "PDF를 여기로 끌어다 놓으세요 · 폴더째 놓아도 됩니다"), 상태는 색 배지(대기 회색·처리 중 파랑·팩 생성 초록·검수 필요 노랑·오류 빨강), 열 폭 최소값, 행 높이 36px
- **처리 속도**: 숫자 상자 → "보통(2회차씩) / 빠르게(4회차씩) / 천천히(1회차씩, 메모리 적은 PC)" 선택
- **아래 고정 실행 띠**: [팩 만들기] 큰 단추 + 진행 막대 + 상태 글 + [멈추기] / 끝나면 [팩 폴더 열기] [검수 보고서]
- Windows 버전에 따라 모양이 달라지지 않게 Qt `Fusion` 스타일 + 자체 스타일시트. 창 최소 크기 960×680, 넓히면 표가 늘어남

### 1-2. 종목 검색 (드롭다운 → 검색창)
- 입력창 하나: "측량", "건안기", "건설안전", "토목" … → 자동완성 목록. 출제기준 프로필이 있는 종목은 ✓ 표시·위로
- 데이터: 공공데이터포털 **국가자격 종목 목록 CSV**(+ 공통 편성기준 CSV의 종목코드)를 앱에 내장 — 인터넷 없어도 검색. **별칭 사전**(건안기·산안기·측량기사·토목·전기기사 …) 추가
- 프로필 없는 종목을 고르면: "이 종목은 아직 출제기준(과목 구성)이 등록되지 않았습니다" + [큐넷 출제기준 자료실 열기](브라우저) + [과목 직접 입력](과목명·문항 수 표) → 프로필 저장. (출제기준 PDF 자동 읽기는 3단계)

### 1-3. 과목 개편 요약 카드 (처리 전에 보임)
- PDF를 넣으면 회차별 과목 머리말을 미리 읽어 출제기준과 대조: "구 6과목 120문항 → 현행 5과목 100문항 · 합쳐짐: 산업안전관리론 + 산업심리 및 교육 → 산업재해 예방 및 안전보건교육 · 이름 바뀜 4 · 제외 0 · 문항별 재배정 필요 회차 0"
- 프로필에 없는 과목명이 있으면 카드에서 바로 연결(지금은 검수 창에서)

### 1-4. 법령·기준 문항 자동 표시 (전처리기)
- 낱말 사전(`standards/law-terms.json`): 공통(법·시행령·시행규칙·고시·기준에 관한 규칙·시방서·KDS·KCS·이상/이하+단위 …) + 종목별(건설안전: 산업안전보건법·안전보건관리규정·유해위험방지계획서·안전관리비·비계·거푸집 동바리·안전대·관리감독자 … / 측량: 공간정보의 구축 및 관리 등에 관한 법률·측량업 …)
- 걸린 문항: 팩 `flags`에 `law`, `lawRefs`에 법령명(예: "산업안전보건법") — **팩 포맷 변경 없음**(칸은 이미 있음, 앱 v0.6 이후 모두 읽음)
- 결과 요약 카드: "법령·기준 관련 1,240문항(18%) · 2021년 이전 회차 47개 — 법령이 개정되어 원본 정답이 현행과 다를 수 있습니다. 법령 문항은 앱에서 현행 기준을 확인하도록 안내됩니다"
- 검수 창 필터에 "법령·기준 문항"

## 2단계 — 앱 v0.10.9 (법령 문항 안내)
- 답한 뒤 화면(정답·오답 모두)에 `law` 문항이면 노란 안내 상자: "법령·기준 문항 — 기출 이후 법령이 바뀌었을 수 있어요. 원본 정답을 외우기 전에 현행 기준을 확인하세요" + [현행 법령 찾아보기](국가법령정보센터 검색: lawRefs 첫 법령명) + 기존 [웹검색](AI 모드 질문에 "현행 기준으로" 추가)
- 학습 기록·추천에는 영향 없음

## 3단계 — 출제기준 PDF 읽기 · 세부항목 기반 재배정
- 큐넷에서 내려받은 출제기준 **PDF**를 끌어다 놓으면 필기 과목명·문항 수·적용 기간·주요/세부/세세항목 표를 읽어 프로필 초안(HWP는 PDF로 저장해 넣기 안내)
- 세부항목 낱말로: 쪼개지거나 합쳐진 과목의 문항별 재배정(지금 재배정 엔진 확장), 신설 항목 문항 수 표시(결손 경고), 범위 밖 의심 문항 검수 필터

## 하지 않기로 한 것(이유)
- 큐넷 화면 자동 읽기(긁기): 공개 API 없음, 자동 조회가 막혀 있음, 구조가 바뀌면 바로 깨짐, 사내망·약관 문제
- 범위 밖 의심 문항 **자동 삭제**: 오탐 시 기출이 사라짐 → 사람 확인(검수 필터)
- 앱이 웹 검색 결과를 직접 요약: 서버·외부 API 없음 원칙(앱은 브라우저로 열어 줌)
- "합격할 수 없는 치명적 위험" 같은 단정 문구: 사실 안내로 대신

## 사용자 결정(2026-10-20)
1. 1단계 범위: 1-1~1-4 전부
2. 앱 법령 안내: 답한 뒤 안내 + [현행 법령 찾아보기]
3. 종목 목록 CSV: 사용자가 내려받아 넣기 — 내려받기(공공데이터포털 "한국산업인력공단_국가자격 종목 목록 정보", "…_국가기술자격시험_공통 편성기준 정보" — 로그인 없이 CSV) → `preprocessor/standards/` 폴더에 넣어 주기(클라우드에서는 data.go.kr 내려받기가 막혀 있음)
