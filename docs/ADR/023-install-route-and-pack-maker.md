# ADR 023 — 설치 루트 재설계 · 이름 '원큐합격 문제팩 생성기' · 생성기 메인 화면

- 상태: 결정·구현(사용자 2026-11-12 세션 #19). ADR 021 7절의 '설치 경로 두 갈래'(세션 #18)를 대체
- 판: 학습앱 v0.15.0 · 문제팩 생성기 0.5.0-dev.6

## 1. 이름: 전처리기 → 원큐합격 문제팩 생성기

- 화면·메뉴·안내문·설치 프로그램·바로가기·Windows 앱 목록·실행파일 정보 모두 **원큐합격 문제팩 생성기**
- 파일 이름: `OneQ-PackMaker.exe` · `OneQ-PackMaker-Setup.exe` · `OneQ-PackMaker-win64.zip`(학습앱 `src/maker.ts` ↔ 릴리스 워크플로, `tests/test_appinfo.py`가 맞춰 봄)
- **그대로 둔 것**: 파이썬 패키지 `oneq_prep`, 팩 `manifest.generator: "oneq-prep x.y"`(팩 형식 `shared/pack-schema.json`의 pattern), 설정 저장 이름 `QSettings("OneQ-Ace","oneq-prep")`, 빌드 파일 이름 `packaging/oneq-prep.*`, 설치 AppId — 바꾸면 이미 만든 팩·설정·업데이트가 끊김
- 업데이트: 같은 AppId라 옛 설치 폴더(`…\Programs\OneQ-Prep`)를 그대로 쓰고, 옛 실행파일·옛 이름 바로가기는 설치 때 지움(`[InstallDelete]`). zip판 [바로가기 만들기]도 옛 이름 바로가기를 지움
- 이미 만든 팩의 `preparedBy`("원큐합격 전처리기 v…")는 학습앱 팩 정보 화면에서 새 이름으로 보임
- **주의**: 새 이름 파일이 붙은 릴리스를 올리기 전까지 학습앱의 [문제팩 생성기 설치 파일 받기]는 404(`releases/latest/download/OneQ-PackMaker-Setup.exe`)

## 2. 설치 루트: 모든 시작은 학습앱 설치

| 단계 | 어디서 | 메인 | 서브 |
|---|---|---|---|
| ① 학습앱 설치 | 학습앱 주소(링크 하나)를 브라우저로 | 설치 안내만 — [PC(Windows)] · [모바일(Android·iPhone)] 탭, 지금 기기 쪽 먼저 | 다른 기기 탭: PC에서는 휴대폰용 QR·주소 복사, 휴대폰에서는 PC로 주소 보내기 |
| ② 처음 실행 | 설치한 학습앱(standalone) | **[문제팩 가져오기]** | PC: "문제팩이 없는 경우 원큐합격 문제팩 생성기를 이 PC에 설치하여 문제팩을 만드세요" + [문제팩 생성기 설치 파일 받기] / 휴대폰·태블릿: "PC에서 학습앱을 설치한 뒤 문제팩 생성기를 설치해 만들어 주세요" — **링크 없음** / 맥: Windows 전용 안내 |
| ③ 문제팩 만들기·보내기 | 문제팩 생성기(Windows) | 작업 순서 ①~④ | ④ [문제팩 공유하기] — 문제팩 파일만 |

- 설치 안내에는 설치 내용만(문제팩 가져오기·생성기 안내 없음). 브라우저에서 설치하지 않고 쓰던 '설치하지 않고 이 브라우저에서 쓰기'는 없앰 — 이미 팩이 있는 브라우저 사용자는 그대로 공부(설정의 문제팩 관리로 추가)
- 기본 설치 위치: PC = Windows 앱 목록(시작 메뉴) + 바탕화면 바로가기 — Chrome은 설치하면 둘 다 만들고(Chromium `windows_pwa_integration`), Edge는 설치 뒤 창에서 「시작에 고정」·「바탕 화면 바로 가기 만들기」를 켜고 「허용」(지나갔으면 `edge://apps` → 세부 정보). 웹앱이 브라우저 설치 창의 선택을 대신 정할 수는 없어 안내로 맞춤. 모바일 = 앱 목록 + 홈 화면(안드로이드 Chrome 설치는 둘 다, 아이폰 「홈 화면에 추가」는 홈 화면 + 앱 보관함)
- 옛 생성기 링크(`?prep`)는 없앰 — 열면 그냥 학습앱 설치 안내. 앱 설정의 '전처리기 링크 복사'도 없앰(학습앱 링크만)
- 설치한 앱의 설정 › 설치 방법은 **다른 기기 탭**부터(PC 학습앱 → 휴대폰 QR). 생성기의 [학습앱 설치] 창(`app_install_dialog.py`)은 없앰 — 생성기는 PC 학습앱 안에서 받으므로 학습앱이 이미 있음
- PC에서 탭 전환은 표시 방식 변화(`display-mode: standalone`)를 듣고 바로 첫 실행 화면으로(`install.ts useInstalledApp`)

### 2.1 실기기 뒤 보완(2026-11-12 오후, 학습앱 v0.15.1)

- PC: Chrome 설치는 제어판 「프로그램 제거」 + 설정 › 설치된 앱 둘 다, **Edge 설치는 설정 › 설치된 앱에만** → Edge 안내에 "제어판에도 보이게 하려면 Chrome으로" 한 줄
- 안드로이드(카카오톡 링크 → 삼성 인터넷): 설치를 누르는 순간 설치 신호가 사라져 화면이 'Chrome으로 설치하세요'로 바뀌었다가 설치 완료로 → 설치 창이 떠 있는 동안은 화면을 바꾸지 않고, 수락하면 바로 **'설치하고 있어요'(돌아가는 표시) → '설치 완료'**. 삼성 인터넷은 Chrome으로 보내지 않고 그 자리에서 설치 안내. 완료 창은 "앱 목록에서 원큐합격 아이콘 / 홈 화면에 두려면 길게 눌러 「홈 화면에 추가」"만
- 안드로이드 [문제팩 가져오기]가 카메라·캠코더·사진 및 동영상만 보이던 것: **앱 코드 탓** — Chrome은 파일 형식이 둘 이상이면 '아무 파일' 선택창을 띄움(Chromium SelectFileDialog) → 안드로이드는 형식 하나(`.zip`)만
- 앱을 지운 뒤 링크를 다시 열면 학습 화면이 같이 보이던 것: 웹앱의 기록은 브라우저 저장소에 있어 **앱을 지워도 남음**(웹이 지울 수 없음 — 안드로이드는 다시 설치하면 이어짐). 그래서 **설치하지 않은 브라우저 화면은 기록이 있어도 설치 안내만** 보이게 함. 기록까지 지우려면 브라우저 설정 › 사이트 데이터 삭제

## 3. 생성기 메인 화면

- 작업 순서 네 단계: **① 종목 선택 → ② 기출 PDF 업로드 → ③ 문제팩 만들기 → ④ 문제팩 보내기**(①은 '출제기준 다운로드'를 뺀 짧은 이름)
- ① 종목은 처음에 **빈칸**(예전엔 측량을 미리 골라 ①에 ✓) — 지난 종목도 기억하지 않음
- ② 안은 2-1·2-2 번호 상자 대신 두 영역 「comcbt.com 최근 기출 받기」·「사용자 직접 올리기」. 직접 올리기 영역 = [PDF 추가]·[폴더 추가] + 끌어다 놓는 상자 + **바로 아래 조건 셋 상시 표시**(접기 없음, 목록이 생기면 상자만 낮아짐). 그 아래 한 목록. 오른쪽은 스크롤 영역(작은 화면에서 목록이 눌리지 않게)
- 실행 띠: ③ [문제팩 만들기] … [문제팩 폴더 열기] | ④ [문제팩 공유하기]. 머리말의 [동료에게 보내기]는 없앰(도움말 메뉴에 '문제팩 공유하기…')
- 실기기 뒤(dev.7): 두 영역 제목 크게·파랑, comcbt 안내 "자동 받기 안 된 이전 회차 또는 최신 회차는 … 아래 「사용자 직접 올리기」에 추가", 직접 올리기 설명 줄 없앰, 조건 제목 "문제팩 생성이 가능한 PDF 업로드 조건", 작업 순서·조건·끌어다 놓기 설명 줄임
- Q-Net 조회 실패: 끊김은 한 번 더 시도, 그래도 안 되면 **전에 받은 이 종목 출제기준(기간 안)으로 계속**(원인 한 줄 표시) — 받아 둔 것이 없을 때만 올리기 상자. 오류 기록 `%APPDATA%\OneQ-Ace\logs\error.log`·`crash.log`(갑자기 꺼짐 원인용). 줄바꿈 글(WrapLabel)의 끝없는 재배치 가능성 막음
- 검수: ADR 024(검수 없이 항상 문제팩)

## 4. 문제팩 공유하기(구 '동료에게 보내기')

- 학습앱·생성기 링크·설치 안내를 모두 빼고 **문제팩만** — 설치는 2절로 일원화했으므로
- 흐름: [문제팩 폴더에서 고르기…](문제팩 폴더가 열림, `oneq-*.zip` 거름) → 한 번에 여러 개 또는 여러 번 나눠 고름(같은 파일은 한 번) → **[선택 완료 · 메시지 복사]** → 메시지가 클립보드에, 그 아래 보내는 방법 ① 보낼 창에 Ctrl+V(메시지) ② **[문제팩 파일 복사]** → Ctrl+V(파일 첨부 — 탐색기 복사와 같은 형식) 또는 목록에서 끌어다 놓기 ③ 보내기. [폴더에서 보기]
- 메시지 = "[원큐합격] 종목 문제팩 n개를 보냅니다" + 파일마다 이름(종목·연도 범위/회차·크기). 고쳐 쓸 수 있음
- 생성기가 직접 보내지는 않음(ADR 021 7절 그대로)

## 검토한 대안

- 메시지와 파일을 한 번에 클립보드에(글+파일 섞기): 붙여 넣는 프로그램마다 글만 또는 파일만 받는 등 결과가 달라 두 단계로 나눔
- 파일 이름(`OneQ-Prep*`)은 그대로 두고 한글 이름만 변경: 사용자가 받는 파일 이름에 옛 이름이 남아 '전수 변경'에 맞지 않음 → 바꾸고 다음 릴리스에서 링크를 맞춤
- 설치 탭 없이 기기 감지 하나만: 다른 기기에 설치하려는 경우(PC → 휴대폰)가 생성기의 [학습앱 설치] 창을 없애면서 갈 곳이 없어 탭으로
