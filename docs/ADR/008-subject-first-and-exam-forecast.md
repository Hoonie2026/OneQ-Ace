# 008. 학습 구조를 과목별 + 모의고사로 단일화, 예상 점수는 실제 시험 기준

- 상태: 확정 (2026-10-18, 세션 #6, 앱 v0.3.0)
- 관련: ADR 003(회독), 004(학습 흐름), 006·007(엔진), 실기기 5a 결과(`docs/device-tests.md`)
- 코드: `app/src/engine/exam.ts`, `engine/session.ts`(`buildSubjectSession`), `src/coach.ts`, `ui/Home.tsx`·`CoachCard.tsx`·`SubjectList.tsx`

## 배경 — 실기기 5a(v0.2.0) 결과

- P2: 100문항을 모두 "모름"으로 푼 상태인데 홈에 **지금 예상 50점**, **"합격권 · 시험일 예상 85점"**. 사용자: 현재 몇 점 → 계획대로 하면 몇 점을 한눈에 보이게
- P6: 경고 화면을 찾지 못함(위 계산 때문에 경고 대신 "합격권"만 뜸)
- P5·의견: 문제팩은 반드시 5~10년치(10회차 이상)를 넣게 된다. 회차별로 전 과목을 연달아 푸는 방식은 초반에 지치고 망각 주기에 맞추기 어렵다.
  **회차별 대신 과목별(전 회차 통합, 중복 문항에 "n회 출제" 표시) + 모의고사(상태 확인)로 단순화**하자
- P9: 모의고사 제출 버튼과 타이머가 한 버튼에 있어 헷갈림

원인(같은 상태를 PC에서 재현):
1. "모름"을 0.15초 만에 누른 기록이 문항당 풀이 시간이 되어 하루 2시간 = 47,368문항으로 계산 → 가용량 폭증
2. FSRS 기본 망각 곡선은 꼬리가 길어, 모름 후 정답을 한 번 본 문항도 17일 뒤 50% 기억으로 본다(엔진 내부 추정치를 "지금 예상"으로 보여 줌)
3. "보유 기출 기준" 예상: 문항 은행이 1회차 100문항뿐이라 "다 익히면 85점". 실제 시험은 대부분 처음 보는 문항

외부 자료: 기출 앱 다산패스(과목별·반복 출제 집중·전 개년 비중 모의고사, 회차별 모드 없음), 다과목 시험 학습 연구 정리(초반 과목별 몰아서 → 후반 섞어서 → 마지막 2주 시간 재는 모의고사), 의학 문제은행 iatroX(자동 배분·간격 복습·실전 모의 세 모드)

## 결정 (사용자 선택)

| # | 결정 |
|---|---|
| 1 | 홈 = 대시보드 + **[과목별 \| 모의고사]** 두 탭. **회차별 풀이·회독 화면은 없앰**(기존 회독 기록은 원장에 남아 엔진이 그대로 씀). 문제팩은 아래 목록에서 가져오기·정보·삭제만 |
| 2 | **과목별 = 핵심 학습**: 과목의 전 회차를 하나로(동일 문항 묶음), [학습] = 15문항 **자동 순서** — 복습할 때가 된 문항(틀린 것 먼저) → 출제빈도 높은 새 문항(같으면 최근 회차). 오늘 이미 푼 문항은 다시 내지 않음(같은 날은 "틀린·모름 문항 다시"). 끝나면 "이 과목 계속" |
| 3 | **오늘 추천**: 엔진이 고른 과목 하나에 배지(진단이 덜 된 과목 → 시험 기준 예상이 가장 낮은 과목). 과목을 섞은 "오늘 학습" 버튼은 없앰(사용자: 선택지가 많으면 혼선) |
| 4 | 풀이 화면 오른쪽 위에 **"n회 출제"** 배지(누르면 출제 회차 목록) |
| 5 | **현재 점수** = 지금까지 답한 그대로(안 푼 문항·모름·오답 0점 — 회차 성적과 같은 셈법) |
| 6 | **시험일 예상 = 실제 시험 기준**: ρ × 보유 기출 기준 투영(ADR 007 outlook) + (1 − ρ) × 처음 보는 문항 정답률. ρ = 반복 출제 비율(보유 회차 실측, 회차가 적으면 측량기사 34회차 실측 10% 쪽으로 — 가상 500문항), 처음 보는 문항 정답률 = 과목별 최근 30개 첫 풀이(모름은 찍어서 25%) |
| 7 | **합격 가능성 카드는 항상 보임**: 상태(진단 중/합격권/빠듯/평균 부족/과락 예상), 과락 과목은 "처음 보는 문항 정답률 a% → 과락을 벗어나려면 b%", "남은 N일 동안 매일 최소 ○분이면 보유 기출 전체를 익힐 수 있음"(+ 적용 버튼) |
| 8 | 문항당 풀이 시간(계획용): 모름·5초 미만·10분 초과 제외, 20건 미만이면 90초, 30초~5분으로 제한 |
| 9 | 모의고사: 남은 시간은 진행 막대 아래 따로, 헤더 오른쪽은 "제출" 버튼만 |

## 영향과 한계

- 학습 엔진 본체(FSRS·계획·게이트)는 그대로 — 게이트는 "보유 기출 기준" 가상 세계에서 검증하고, 화면의 실제 시험 기준 예상은 그 위에 얹는 층(코치)
- 실제 시험 기준 예상은 ρ가 작아(약 10%) **처음 보는 문항 정답률이 점수 대부분을 정한다** → 기출 암기만으로는 과락 예상이 나오는 것이 정상. 공부할수록 처음 보는 문항 정답률(최근 30개)이 올라 예상이 따라 오른다
- 미반영(백로그): 처음 보는 문항 정답률의 학습 곡선 외삽(공부량 → 시험일 정답률), 6단계 유사 문항 군집으로 ρ 보정, 후반(마지막 2주) 과목 섞기 학습 권장
- 앱 v0.3.0. e2e 3단계 게이트 시험은 회차별 대신 과목별 학습으로 바꿔 같은 백업·복원 검증을 유지
