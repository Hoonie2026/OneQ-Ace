# 004. 학습 화면 흐름 재정의 — 실기기 2차 요구사항의 단계 배치 (계획)

- 상태: 계획 확정 (2026-10-15, 세션 #3). 구현은 표의 단계에서
- 관련: 개발기준서 6.4·6.5·7.1·8장, ADR 003

## 배경

실기기 2차에서 "학습 흐름이 직관적이지 않다"는 의견과 함께 목표 흐름이 제시됐다:
자격종목 선택 → 시험일(달력) → 주간 학습 목표 자동 계산, 그리고 학습을 **회차별·과목별·모의고사** 세 가지로 나눠 이력 관리.

## 결정 — 화면 구조

```
홈(종목 선택) ─ D-day · 예상 점수 · 이번 주 목표 · [오늘 학습 시작]
 ├ 회차별   : 회차 목록(미시작 / 진행 중 n/100 / 완료 + 최근 점수), 회독 이력 누적
 ├ 과목별   : 종목의 전 회차를 과목으로 묶음. 문항마다 출제빈도 표시, 동일 > 유사 > 1회 순
 └ 모의고사 : 전 회차에서 과목별 20문항씩 출제, 실제 시험시간, 성적만 이력
```

"오늘 학습 시작"(6.5의 자동 구성 세션)은 세 모드와 별개로 홈의 큰 버튼으로 둔다. 무엇을 풀지 고르기 싫은 사용자를 위한 기본값이다.

| 5.1 | 시험일 달력 선택 | 5단계(첫 실행·설정) | 종목별 시험일. `<input type="date">`(기기 기본 달력) |

| 5.3 | 합격한 종목 삭제 | ✅ v0.1.3 | 설정 → 자격종목 관리 |

## 확인이 필요한 점(해당 단계 시작 전)

- 과목별 통합은 **과목 번호**로 묶는다. 같은 종목이라도 출제기준 개편으로 과목 구성이 바뀐 연도가 있으면 과목 이름이 달라진다 → 4단계에서 보유 팩의 과목명을 대조해 다르면 사용자에게 묶을지 묻는다.
- 모의고사 출제 비율(약점 위주 vs 출제빈도 위주 vs 무작위)은 4단계 시뮬레이션으로 정한다.
