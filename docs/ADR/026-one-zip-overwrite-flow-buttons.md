# ADR 026 — 문제팩은 종목 파일 하나, 학습앱은 덮어쓰기, 생성기는 작업 순서대로 잠금

- 상태: 결정·구현(사용자 2026-11-17 PC 시험) · 생성기 0.5.0-dev.29, 학습앱 v0.17.0. ADR 021 6·8절, ADR 024 6절(직접 고치기)을 고침

## 배경(사용자 PC 시험 2026-11-17)

- 콘크리트기사로 문제팩을 다 만들고 공유한 뒤 건설안전산업기사를 조회하니, 올린 목록에 콘크리트기사 기출이 남은 채 새 출제기준으로 오류가 표시됨
- 작업 순서가 왼쪽 패널에만 보여 지금 무엇을 할 차례인지, 시스템이 무엇을 하는 중인지 알기 어려움
- 여러 종목 PDF를 한꺼번에 올리면 조회하지 않은 종목 PDF까지 목록에 들어감
- 진행 막대가 끝날 때 한꺼번에 참
- 회차별 zip이 여러 개 생기고, 처리 보고서·검수 파일은 쓰이지 않음

## 결정

1. **생성기 결과 = 종목마다 압축 파일 하나** 「원큐합격 문제팩_종목_첫해-끝해(n회차).zip」(문제팩 폴더 바로 아래, 같은 종목의 예전 파일은 지움). 회차가 하나여도 같은 모양. 회차별 팩은 안쪽 `.회차별` 폴더(Windows 숨김)에 두고 판 비교·정답 교차 확인·묶음 재료로만 씀(예전처럼 바깥에 있던 회차 팩은 처음 쓸 때 옮김). [문제팩 공유하기]도 이 파일을 그대로 보냄('보낼 문제팩' 복사본 없앰)
2. **처리 보고서(report.html)·검수 파일·검수 창·[직접 고치기]를 없앰** — `report.py`·`review.py`·`gui/review_dialog.py` 삭제. 경고·의심 문항은 학습앱에서 학습자가 바로잡는 쪽으로(다음 세션 — 지금은 '정답 확인 필요' 표시까지, ADR 024)
3. **학습앱 [문제팩 가져오기]는 압축 파일 하나로 일원화**: 고른 파일을 한 번만 읽어, 이름과 관계없이 안을 보고 묶음이면 펼침. **이미 있는 회차는 판과 관계없이 덮어씀**(묻지 않음, 학습 기록은 contentHash로 이어짐). 내용까지 같으면 그대로(`importPackBytes({overwrite: true})`)
4. **작업 순서 버튼**: ① [조회] → ② [기출 PDF 웹검색] → ③ [문제팩 만들기] → ④ [문제팩 공유하기] 중 지금 할 단계 버튼만 파랑, 나머지는 회색. 조회·PDF 읽기·문제팩 만들기 중에는 네 버튼과 종목 입력 칸을 모두 잠금(멈추기만). 문제팩 만들기 중에는 ②의 끌어다 놓기 상자·[폴더에서 선택하기]·[선택 빼기]·[모두 비우기]·표 고치기·창에 끌어다 놓기도 잠금(dev.35)
5. **종목 바꾸면 목록 비움**: 다른 종목을 조회하거나 문제팩을 다 만든 뒤 다시 조회하면 올린 기출 목록·묶음 안내를 비움. 기출을 한 번 올리면 문제팩 만들기가 끝날 때까지 [조회]·종목 칸을 잠금(dev.31 — [모두 비우기]로도 안 풀림, 올리기 전에는 조회 가능, 처음 상태로 되돌리기는 풀림)
6. **조회한 종목이 아닌 기출 PDF는 넣지 않음**: 머리말에서 다른 종목으로 읽힌 PDF는 목록에서 빼고 경고창(파일 이름 — 읽은 종목)
7. **진행 막대** = 처리하는 회차들의 단계 진행(읽기·문항 나누기·정답·정답 확인·팩) 평균, 끝나면 100%
8. **정답 표시가 없는 PDF**(dev.32): 정답을 찾은 문항이 절반이 안 되면(학생용 등) 회차 전체를 만들지 않고(상태 '만들지 못함') 끝난 뒤 안내 상자에 파일 이름과 '정답이 표시된 PDF로 다시 올려 주세요(조건 2)'. ②(올리기)에서 거르지 않음 — 형광펜·끝 정답표·스캔본은 문항 나누기·정답 읽기를 해야 판단할 수 있어, 첫 쪽만 읽는 목록 미리 읽기로는 잘못 거를 수 있음
