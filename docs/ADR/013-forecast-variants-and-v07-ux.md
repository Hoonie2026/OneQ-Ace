# 013. 시험일 예상 점수 재검토(변형 기출·개념 군집·직전 복습)와 v0.7 화면 정리

- 상태: 확정 (2026-10-19, 세션 #8) — 앱 v0.7.0
- 관련: ADR 007(합격 기준 경고), 008(실제 시험 기준 예상), 011(학습량 전이), 006(동일 문항), 002(백업·삭제)
- 계기: 실기기 v0.6.0 의견(사용자, 측량 31회차 팩)

## 1. 예상 점수가 왜 41.1점이었나 — 재현과 원인

같은 조건(31회차 팩, 시험일 2027-04-01, 하루 1시간·주 6일, 오늘 2026-10-19, 풀이 기록 없음)을 클라우드에서 재현하면 **정확히 41.1점**.

| 원인 | 내용 |
|---|---|
| ① 반복 출제를 "글자가 같은 문항"만으로 셈 | ρ = 9.5%. 시험의 90%를 "처음 보는 문항"(찍기 25% + 전이)으로 계산 → **기출 2,816문항을 다 익혀도(하루 3시간) 51.4점이 상한** |
| ② 변형 문항을 따로따로 처음부터 익힌다고 봄 | 숫자·표현만 바꾼 같은 개념도 각각 "새 문항 3.6회 풀이" 비용 → 전부 익히는 데 하루 94분 |
| ③ 시험 직전 집중 학습의 효과 없음 | 날짜별 시간을 늘려도 "새 문항 더 익히기"에만 쓰여 +0.9점. 이미 익힌 문항을 직전에 다시 보는 효과(기억률 상승)는 모형에 없었음 |
| ④ 과목 배분이 한쪽으로 쏠림 | 효율이 같으면 앞 과목부터 88.8점까지 채우고 나머지 셋은 45점 — 과목별 예상이 비현실적 |

## 2. 근거 — 보유 기출로 직접 잰 "기출 반복" (외부 자료와 대조)

측량 34회차 문항을 앞 회차와 글자 2-gram 코사인 유사도로 대조(전처리기 `reassign.py`와 같은 방식):

- 0.6 이상이면 같은 개념의 변형(예: 측량기본계획에 포함되지 않는 사항 2013↔2016 0.72, 논리연산 AND 2016↔2020 0.76, 교호수준측량 D점 표고 2014↔2017 0.68). 0.5대는 주제만 같은 경우(클로소이드 일반)가 섞여 0.6을 경계로 둠. 편평률 계산(0.55)처럼 확실한 변형도 빠지므로 **보수적**.
- **앞 회차를 몇 회차까지 가졌느냐에 따라** 크게 다르다(회차마다 바로 앞 k회차와 대조):

| 보유 앞 회차 k | 1 | 3 | 5 | 8 | 12 | 16 | 20 | 25 | 30 |
|---|---|---|---|---|---|---|---|---|---|
| 같은 문항(≥0.9) | 0% | 0.3% | 0.5% | 3.7% | 13% | 22.5% | 29.9% | 37.6% | 42.7% |
| 변형(0.6~0.9) | 1.6% | 4.8% | 7% | 10.6% | 16.7% | 21.2% | 22.5% | 22.6% | 24.2% |

  같은 문항은 바로 앞 몇 회차에는 거의 없고 **3년(8회차) 이상 거슬러 올라가야** 나온다 — 오래된 문항을 다시 쓰는 출제 방식. 30회차를 가지면 기출(같은+변형) 약 67%.
- 외부 자료: 수험생 경험담 "기출 50~70%, 신유형 10~20%"(에듀윌 지식인 답변 모음)와 같은 범위. 측량및지형공간정보기사 필기 합격률 2020~2025년 33~40%(응시자 기준).

## 3. 결정

1. **시험 구성 = 같은 기출 + 변형 + 처음 보는 문항**(`engine/similar.ts`, `exam.ts examScoreMix`)
   - 비율은 보유 팩에서 직접 잰다: 뒤쪽 절반 회차를 앞 회차 전체와 대조. 위 실측 곡선(보유 회차 × 0.75 깊이)으로 300문항만큼 당긴다. 측량 31회차: 같은 31.7% · 변형 23.2% · 처음 45.1%(기출 약 56%).
     최근 회차(2022 이후 CBT 비공개)가 비어 있어, 보유 회차 전체 깊이(약 67%)가 아니라 측정 깊이 값을 그대로 씀 — 보수적.
   - 점수 = 같은×기출 점수 + 변형×(r + 0.7×(기출 점수 − r)) + 처음×r. r = 처음 보는 문항 정답률(ADR 011 전이 포함), 0.7 = `VARIANT_TRANSFER`(가정, 백로그).
2. **개념 군집**: 같은 과목 안 유사도 ≥ 0.6 학습 단위를 묶는다(단일 연결 — 측량 2,816단위 → 1,921군집, 가장 큰 군집 19). 글자 2-gram 12종 미만(그림·수식뿐)은 묶지 않음.
   - 아직 안 푼 문항이라도 같은 군집 문항을 익혔으면 p = prior + 0.7×(익힌 문항 p − prior)(`predict.ts itemExamP`).
   - 투영(`outlook.ts`): 아무것도 안 익힌 군집은 "대표 + 변형" 한 행동(비용 = 새 문항 + 변형 1.7회씩), 일부 익힌 군집의 나머지는 변형 1.7회.
   - 계산은 Node 약 0.4~0.5초 → 팩 구성(packId·버전)이 같으면 `settings['concepts:<종목>']`에 캐시, 종목 삭제 시 함께 지움.
3. **과목 배분은 가장 낮은 과목부터**(물 채우기) — 과락이 있는 시험이라 고르게 올리는 쪽(plan.ts의 합격 확률 기여도와 같은 방향).
4. **시험 직전 복습**: 시험 전 3일(달력)의 학습시간은 이미 익힌(또는 투영에서 익힌) 문항을 효과 큰 순으로 1회씩 다시 보는 데 먼저 쓴다 → 시험일 기억률 0.85 → 0.95(`LATE_R`). 남으면 새 문항.
5. **전이는 익힌 기출의 양에 비례**: 과목당 학습 단위가 500(측량 31회차 ≈ 560)에 못 미치면 비례해 줄임(2회차 팩을 다 외워도 처음 보는 문항 실력이 크게 오르진 않음).
6. **자신 없이 맞힘(unsure)** = 답하기 전 웹검색(또는 예전 "헷갈림"). FSRS Hard, 첫 풀이 정답률(prior·처음 보는 문항 정답률)에서는 찍은 것(25%)으로 — 검색해서 맞힌 것이 실력으로 부풀지 않게.

### 결과(같은 조건 재현)

| 계획 | 이전(v0.6.0) | v0.7.0 |
|---|---|---|
| 하루 1시간·주 6일(140.6시간) | 41.1 | **56.9** |
| + 시험 전날·전전날 5시간 | 42.0(+0.9) | **57.7(+0.8)** — 학습 계획 화면에 "날짜별 학습시간 반영: +8.3시간 → +0.8점"으로 따로 표시 |
| 하루 3시간(421.7시간) | 51.4(상한) | **68.5** |
| 과목별(1시간) | 44 / 44 / 40 / 39 / 39 | 56.5 ~ 56.7(고르게) |

- 1시간 계획은 여전히 합격선(60) 아래: 31회차 전부를 익히려면 하루 약 78분이 필요하고(합격 기준 경고가 안내), 처음 보는 문항(45%)은 기본 실력 25% + 전이로만 오르기 때문. 실제로 풀기 시작하면 처음 보는 문항 정답률이 실측으로 바뀐다(풀이 기록 없음 = 찍기 25% 가정).
- 시험 직전 이틀 5시간은 **+0.8점**: 총 학습량이 6% 늘고, 직전 복습으로 익힌 문항의 기억률이 오르는 만큼. "분명히 도움이 된다"는 방향은 맞지만 크기는 작다 — 대신 화면에서 반영 여부와 크기를 숫자로 보여 준다.
- 게이트(`npm run gate`, 가상 학습자 27 시나리오) 그대로 통과. 가상 학습자 문항은 글자가 짧아 군집이 생기지 않으므로 ① 변형·② 군집 효과는 게이트에 들어가지 않음 — 실사용 기록으로 보정(백로그).

## 4. v0.7 화면 정리(사용자 요청)

| 요청 | 결정 |
|---|---|
| 자격종목 선택 | 가로 단추 → **드롭다운**(종목명 · 회차 수) |
| 처음 보는 문제의 개념 | 하단 "모름" 영역을 **모름 \| 🔎 웹검색** 둘로. 지문에서 문제 꼬리("~에 대한 설명으로 옳지 않은 것은?")·숫자 값·"(단, …)"를 뺀 핵심 낱말 + 과목명으로 구글 검색(새 탭). 모의고사에는 없음. 답한 뒤에도 "개념 검색" |
| 헷갈림 | 삭제(대신 검색 후 답하면 자동으로 "자신 없이 맞힘") |
| 한 줄 설명 | **메모**(500자). 메모가 있는 문항은 다시 풀 때 **📝 메모 있음**(보라색 — 정답 초록·오답 빨강·출제 횟수 주황과 구분), 답한 뒤 메모 내용. 다른 회차의 같은 문항 메모도 보여 줌 |
| 데이터 지우기 | **학습 기록만 지우기**·**문제팩 지우기** 모두 자격종목을 고른 뒤 실행(모든 종목도 가능). 문제팩 지우기는 종목 → 팩 목록 → 전체/부분 선택 → **그 팩 문항의 학습 기록까지 함께 삭제**. 전체를 고르면 종목 삭제(학습 계획까지) |
| 종목 삭제 | 문제팩·학습 기록·학습 계획 모두 지움(전부터 그렇게 동작). 단추는 위 "문제팩 지우기"를 그 종목 전체 선택으로 연다 — 삭제 코드는 한 곳 |
| 문제팩 목록 | 현황 조회 + 가져오기만. 팩 상세의 개별 삭제 단추 삭제(예전 개별 삭제는 기록을 '매핑 대기'로 보관했으나 일원화하면서 기록도 지움) |

## 검토했으나 보류

- 유사도 0.5를 변형 경계로: 기출 비율이 61%로 더 높지만 주제만 같은 문항(클로소이드 일반 41문항 군집)이 섞임
- 보유 회차 전체 깊이(30회차 → 67%)를 그대로 쓰기: 최근 4년(2022-2 이후 CBT 비공개)이 빠진 팩이라 과장 우려
- 전처리기에서 clusterId를 채워 팩에 넣기: 팩 구성이 바뀌면 군집 id가 달라져 모든 팩을 다시 게시해야 함 → 앱에서 계산
- 웹검색을 앱 안 창으로: PWA에서 외부 사이트 iframe은 대부분 막힘(구글 X-Frame-Options) → 새 탭
