# ADR 024 — 검수 없이 항상 문제팩을 만든다

- 상태: 결정·구현(사용자 2026-11-12 PC 시험 뒤 세션 #19 이어서) · 생성기 0.5.0-dev.7, **3절 개정 dev.8(C 교차 확인 → B 표시, 사용자 같은 날 저녁)**. ADR 021 6절('의심 문항만 검수')을 대체

## 배경

- PC 시험: 건축기사 20회차가 모두 '검수 필요'로 빠져 **문제팩이 하나도 안 만들어짐**. 이유는 회차마다 단 하나 — 시험지 과목명 '건축법규'가 출제기준 '건축관계법규'와 글자가 달라서
- 사용자: "시험을 준비하는 사람은 그 과목을 모르는데 검수 화면이 요구하는 판단을 하려면 그 종목을 공부해야 함 — 넌센스"
- 즉 검수가 **막는 장치**로 작동했고, 막힌 내용 대부분은 기계가 판단할 수 있는 것(과목명 맞추기)이거나, 사람도 판단 못 하는 것(정답 맞히기)

## 결정

1. **파일 단위 경고는 막지 않고 참고(보고서)로**: 문항 경계·정답표 칸 수·형광 표시 일부만 지움·스캔본 문항 수 등
2. **과목명 자동 대응**(`Profile.guess`): 정확히 같지 않으면 ① 이름이 들어 있거나 글자 순서대로 포함·비슷함 0.6 이상(2등과 차이 0.1) ② PDF 과목 수가 출제기준과 같으면 같은 순번. 이미 다른 과목이 차지한 표준 과목은 안 씀. 못 맞추면 그 과목만 뺌(보고서에 적음)
3. **정답을 믿을 수 없는 문항**(`pack.unsure_answer`: 정답 못 찾음 · 보기 표시 ≠ 정답표 · 정답 번호가 보기 수를 벗어남 · 정답 표시가 여러 개 · 정답 표시가 남아 보임. 정답표 칸 수가 문항 수와 다르면 정답표 전체를 믿지 않음) — dev.8(사용자 결정):
   1. **C 교차 확인 먼저**(`crosscheck.py`): 같은 문항(발문·보기 글이 같음 — 번호·공백·부호 무시)이 이번에 함께 처리한 회차나 문제팩 폴더의 기존 팩에 믿을 수 있는 정답으로 있으면 그 정답(보기 순서가 다르면 정답 보기의 글로 위치를 찾음). 찾은 정답끼리 다르면 쓰지 않음. answerSource "cross-check"
   2. **그래도 안 되면 B 표시**(`pack.settle_doubts`): 정답 후보가 있으면 넣고 flags "answer-unsure" + 다른 후보도 acceptAlso로 인정 → 학습앱이 답한 뒤 "⚠ 정답 확인 필요 — [웹검색]이나 교재로 확인" 안내
   3. 정답 후보가 없거나(정답 못 찾음) 보기 수를 벗어나거나 정답 표시가 그림에 남은 문항만 뺌(manifest.excluded "other", "자동 제외: …")
4. **구기준 회차 과목 재배정은 자동**: 확신 0.6 이상 제안만 적용, 나머지는 시험지 과목 그대로
5. 막는 경우는 **다른 종목 문서**뿐(상태 '만들지 못함')
6. 검수 화면은 **선택**: 결과 화면의 작은 [직접 고치기(선택)] — 원본을 보고 정답을 아는 사람만. '검수 필요' 상태·문구는 없앰, '검수 보고서(웹)' → '처리 보고서'

시험: 사용자의 건축기사 PDF 3회차로 확인 — 3회차 모두 팩 생성, '건축법규 → 건축관계법규(자동 — 이름이 비슷함)', 묶음 1개(`tests/test_standards.py`·`test_batch.py`에 규칙 시험)
