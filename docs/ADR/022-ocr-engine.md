# ADR 022 — 스캔본 OCR 엔진: Windows 내장 OCR(PREP-PLAN-v0.5 B1)

- 상태: 결정(사용자 2026-11-11 16:59 "동료 PC에도 내장되어 있는 것만으로") · 구현·실측 완료(세션 #16, 🖥P25)
- 근거 자료: 🖥P5 비교(`oneq_prep/ocrbench.py`, 정답 `tests/fixtures/ocr/railway-2010-2-gt.json`), 표본 `source_pdf/철도보선기사_스캔본.pdf`(2010년 2회, 10쪽, 실제 종이 스캔 ≈120dpi)

| 엔진 | 본문 글자 맞춤(×2) | 95%↑ 단위 | 정답표 100개(칸 나눠 읽기) | 쪽당 |

## 결정
1. 스캔본 OCR = **Windows 내장 OCR만**(배포 설치 프로그램에 다른 엔진 넣지 않음). 한국어 Windows는 한국어 OCR 기능이 보통 미리 설치됨(사용자 PC 🖥P3 확인). 없으면 Windows 11은 일반 사용자도 [설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션]에서 추가 가능(회사 정책으로 막혔으면 IT) — 전처리기가 스캔본을 만났는데 기능이 없으면 이 경로를 안내
2. OCR은 스캔본에만 필요 — 글자 PDF(comcbt 교사용 등)는 OCR 없이 처리
3. 기존 Tesseract 경로(`ocr.py`)는 지우지 않고, 직접 설치된 PC에서만 예비로 자동 사용
4. 끝 쪽 정답표는 칸 나눠 읽기(ocrbench의 `table_rows`·`_strip`·`_letters`를 본 경로로 옮김). **손글씨 ✓ 표시는 정답으로 쓰지 않음**(표본 1번·9번 모두 시험 본 사람의 오답 표시). 문항 그림에서 지우지도 않음(사용자 2026-11-11 18:35: 앱이 정답을 표시하고 웹검색도 있음)
5. 보기 번호 **가나다라**도 읽음
6. 글자 맞춤 92.9%는 완벽하지 않음("시엔트" 등) → 스캔본 문항은 지금 설계대로 `ocr`·`needs-review` 표시, 의심 문항만 검수
7. 🖥P14 때 동료 PC 한 대에서 한국어 OCR 기능 기본 설치 여부 확인(`Get-WindowsCapability -Online | ? Name -like 'Language.OCR*'`)

## 구현(세션 #16) — `oneq_prep/ocr.py`·`extract.py`·`pack.py`
- 엔진: Windows 내장(winocr, ko) → 없으면 직접 설치된 Tesseract → 둘 다 없으면 [설정] 안내(창 프로그램은 처리 전 노란 상자). 점검 `py -3 -m oneq_prep.ocr --check`, 실행파일 `--ocr-check`(GitHub 빌드가 확인). `ONEQ_OCR_ENGINE`으로 강제. 렌더는 긴 변 3000px 상한, 낱말 사이 공백은 글자 높이 0.6배 초과일 때만
- 가나다라 보기: 줄 첫머리·넓은 간격 뒤 "가." 꼴을 번호로, 문항 안 마지막 "라"부터 거꾸로 골라 잡음 제거, 셋이면 2×2 배치로 채움. 손글씨 표시는 정답 판정에 안 씀
- 정답표: 끝 쪽 격자 표를 칸으로 잘라 읽고 그 쪽은 문항 찾기에서 뺌. 제목 줄(칸 수 다름)은 빼고, **번호 줄 = 바탕 칠한 줄**(또는 숫자 많은 줄), **나머지는 모두 답 줄 — 건너뛰지 않음**(건너뛰면 뒤 정답이 통째로 밀림). 덜 읽은 답 줄은 반씩 → 줄 통째 → 앞 답 줄과 함께(winocr) → 세 칸씩 → 칸마다 → **같은 표의 확실히 읽은 칸을 견본으로 글자 모양 맞춤**(거리 ≤ 둘째의 0.85배) → 끝내 애매하면 검수. 정답은 시험지 번호로 붙임
- 스캔본 배치: 단 구분은 글자 분포로, 단 왼쪽 끝은 쪽·단마다 문항번호 줄 x를 높이에 대한 직선으로(종이 기울기), 크롭 폭은 글줄 범위, 꼬리말(쪽 아래 한글 없는 줄) 빼기, 과목 머리말은 "•."·";" 구분도 받고 이름을 못 읽으면 출제기준 순서로, 문항번호 "9,"도 받음
- 번호를 못 읽은 문항: 앞 문항 "라" 줄 뒤에서 문항번호 자리로 시작하는 줄로 되찾음(경고), 순서로 매긴 번호 뒤 진짜 번호가 나오면 합침, 끝내 못 찾은 번호는 `manifest.excluded`(unreadable) — 검수 마침이면 팩
- 회차: 첫 쪽 위쪽만 OCR해 처리 전 목록에도 표시, "2010년 기사 제2회" 머리 읽기
- 배포: `requirements.txt`에 `winocr; sys_platform == "win32"`, PyInstaller에 winrt 하위 모듈, THIRD-PARTY-NOTICES
