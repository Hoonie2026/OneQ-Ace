# ADR 029 — 회차별 학습 다시 넣기

- 상태: 결정·구현(사용자 2026-11-17) · 학습앱 v0.19.0. ADR 008·020(홈에서 회차별 풀이를 없앰)을 바꿈

## 결정

- 학습 방식 = **시스템 추천 · 과목별 · 회차별**(+ 모의고사). 홈 [시스템 추천 학습] 아래 한 줄에 [과목별 학습 | 회차별 학습]
- 회차별 학습 화면: 고른 종목의 회차를 최근 것부터 한 줄씩 — 연도·회차, 문항 수, 지금 회독 진도(막대)·몇 회독째.
  누르면 시험지 순서대로 이어 풀기(처음이면 1번부터, 다 풀었으면 성적). 푼 것이 있으면 [지금까지 성적], 오답·모름이 있으면 [오답·모름 n문항 다시 풀기]
- 풀이·성적·합격선 판정·회독 이력·[처음부터 다시 풀기(새 회독)]은 기존 회독 기능(ADR 003, `Target {kind:'pass'}`) 그대로 —
  회차 풀이도 학습 기록(FSRS·누적 점수)에 똑같이 들어감
- ✕로 나가거나 성적에서 [다른 회차 고르기] → 회차별 학습 화면으로(과목별 학습과 같은 방식)
