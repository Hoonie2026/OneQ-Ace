- 상태: 확정 (2026-10-20, 세션 #8 이어서) — 앱 v0.10.0
- 관련: ADR 002(백업·복원 합치기), 006(FSRS), 012(전처리기), 013·014(예상 점수)
- 사용자 결정(이번 세션): ① 기기 간 공유는 **백업 파일 맞추기 개선**(서버 없음 유지) ② [쉬움] = **FSRS Easy** 등급 ③ 정답 화면에 **[모름으로 바꾸기]** 둔다 ④ 손글씨 메모는 **문항을 넘기면 지움**

## 1. 저장 위치와 백업 안내 (v0.9.2)

- 사실 확인
  - Android Chrome: 설치 앱도 브라우저 사이트 데이터를 같이 쓴다. 영구 저장(`persist()`)은 공간 부족 때 **자동 삭제만** 막고, 사용자의 "인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터"는 막지 못한다
  - iOS: 홈 화면 앱은 **Safari와 저장소가 따로**(WebKit 버그 181849) — Safari 탭에서 팩을 넣고 홈 화면에 추가하면 앱은 빈 상태. Safari의 "7일 미사용 삭제"는 홈 화면 앱에 적용되지 않는다(WebKit 해명). `persist()`는 Safari 17부터, 홈 화면 앱이면 허용 가능성이 높다. 아이콘 삭제 시 데이터 삭제는 실기기 확인(Y2)
- 결정: 설정의 "학습 기록 백업"과 "저장공간"을 **「내 학습 기록 지키기」 한 카드**로 — 저장 위치(기기·브라우저·설치 여부 감지 `util.deviceEnv`·`storagePlace`) → 이럴 때 지워집니다 → 지키는 방법 → 영구 저장·마지막 백업 상태(신호등 색) → 백업·공유·복원 → 다른 기기와 이어서 공부하기(접기) → 사용량·기록 지문
- iOS 브라우저 탭에서 열면 설정에 경고, 홈 설치 안내에 "따로 저장" 한 줄

## 2. 태블릿·PC와 기기 간 이어 학습 (v0.9.2·v0.10)

- 지금도 설치·실행은 되지만 화면이 휴대폰용이었다(태블릿 세로는 아래 절반이 빔, PC는 그림이 커서 보기가 밀림)
- 화면: 폭 900px 이상(태블릿 가로·PC)과 가로 휴대폰은 풀이 화면 **두 단**(왼쪽 문제 그림 / 오른쪽 해설·계산 도구·보기), 홈은 폭 960px 이상 두 단, 그 밖 화면은 760px 폭. PC 키보드 1~4·M(모름)·E(쉬움)·Enter·←→
- 기기 간 맞추기 — 검토한 대안
  - A. **백업 파일 주고받기 개선(채택)**: 복원은 이미 합치기(uid). 빈틈 두 가지를 메움 — 학습 계획(`plan:종목`)은 `updatedAt`을 달아 **더 최근 것이 이김**(마지막 백업 시각·고른 종목 같은 기기별 값은 그대로), 설정 카드에 "다른 기기와 이어서 공부하기" 4단계 안내
  - B. 사용자 본인 Google 드라이브 앱 폴더(`drive.appdata` — 민감하지 않은 권한, 기본 앱 검증) 자동 동기화: Google Cloud 등록·로그인·사내망 차단 가능성, "외부 API 없음" 원칙 변경 → 보류(BACKLOG)
  - C. 자체 서버·BaaS: 서버 운영·개인정보·대회 범위 초과 → 기각. 기기 간 직접 전송(QR·WebRTC)은 기록 크기·중계 서버 필요로 기각

## 3. 계산 도구 (v0.10)

- 풀이 화면 아래 **[계산기] [메모]** 항상, 계산 문제면 마지막에 쓴 도구가 저절로 열림(설정 → 풀이 화면에서 끔). 모의고사에도(실제 시험도 계산기 허용)
- 계산기(`calc/expr.ts`, eval 없는 재귀 하강 해석기 + 단위 시험): 사칙·괄호·^·²·³·√·∛·sin/cos/tan과 역함수(DEG/RAD)·log(밑 지정 가능)·ln·10ˣ·eˣ·π·e·×10ⁿ·Ans, **도·분·초 입력과 →도분초 표시**(측량), Pol·Rec. 우선순위는 카시오 fx-570 계열과 같게(-2^2 = -4, 곱 생략 2π)
- 메모(`ui/Scratchpad.tsx`): 캔버스 + Pointer Events, 펜 압력, 펜을 쓰면 손가락 터치 무시(손바닥), 지우개·되돌리기·모두 지우기, 다크 모드, 저장 안 함
- 계산 문제 판정(`calc/detect.ts`)
  - 팩 문항 flags에 `calc`·`no-calc`(전처리기·검수자 확정, 스키마에 추가 — 선택 값이라 예전 팩·앱과 호환)가 있으면 그대로
  - 없으면 문항 글자로 추정: 보기 대부분이 숫자 + 지문 숫자, 또는 "구하면·얼마·값은…" + 지문 숫자 2개 이상. 측량 2022-1회차 26문항 판정, 눈 검토 오판 1(18번 축척계수 — 암기). 잘못 열려도 닫으면 그만이라 넓게 잡음
  - **전처리기 방향**: 같은 판정 + 검수 보고서에서 켜고 끄기 → flags로 팩에 확정(다음 세션 첫 작업 후보)

## 4. 웹검색은 답한 뒤에만 (v0.9.2)

- 풀기 전 [웹검색] 삭제, 정답·오답 화면의 [웹검색]만. 검색해서 맞힌 기록이 성적을 부풀리는 길이 없어졌으므로 "자신 없이 맞힘(unsure)" 보정 로직을 지움: FSRS Hard, 첫 풀이 정답률·처음 보는 문항 정답률의 25% 처리, 옛 헷갈림 함수
- 옛 기록의 `unsure`는 DB·백업 호환으로 칸만 남기고 읽지 않는다(그 기록은 보통 정답으로 셈 — 건수가 적어 영향 작음). 기록 지문 계산식은 그대로라 이전 백업과 비교 가능

## 5. [쉬움] (v0.9.2)

- 하단 [모름] [쉬움](모의고사 제외). 누르면 보기 없이 정답 기록(`chosen` = 정답 번호, `easy: true`) → 정답 화면("✓ 쉬움")
- 학습 알고리즘: FSRS **Easy** 등급(첫 복습 약 2주, 계속 쉬우면 몇 달 간격, 나중에 틀리면 Again으로 다시 짧게). 첫 풀이 정답률·예상 점수에서는 정답
- **풀이 시간 추정에서 뺀다** — 읽자마자 누르므로 넣으면 문항당 시간이 짧게 잡혀 하루 문항 수가 부풀려짐
- 정답 화면 [모름으로 바꾸기]: 그 기록을 모름으로(묶음 끝 다시 풀기에 들어감, 오늘 진행 수도 고침)
- 백업: `easy`는 선택 필드, 지문에는 있을 때만 `|e`를 붙여 예전 백업과 지문이 같다

## 7. v0.10.2 — 실기기 Z1~Z6 결과 반영(2026-10-20)

- 결과: Z1·Z2·Z3·Z6 PASS, Z4·Z5 보완
- **Z4**: 안드로이드 태블릿의 기본 브라우저가 Firefox이면 메일(Gmail) 링크가 Firefox로 열린다. 태블릿 Firefox·Chrome은 "데스크톱 사이트" 모드일 때 Android 대신 `X11; Linux x86_64`를 보내 앱이 PC로 판단했다
  - 판정: Android 표시가 없어도 Linux + 터치 화면(maxTouchPoints > 1)이면 안드로이드 태블릿
  - 안내: 안드로이드에서 Chrome이 아닌 브라우저(Firefox·Edge·웨일 등)는 **[Chrome으로 열기]**(intent 주소)를 먼저 — 브라우저마다 기록이 따로이므로 설치·학습은 Chrome 한 곳. 그 브라우저에 그대로 설치하는 방법(⋮ → 설치·홈 화면에 추가)은 셋째 줄로. 삼성 인터넷은 설치 단추가 뜨면 그대로 설치
- **Z5**: PC Chrome·Edge는 설치 직후 **지금 탭을 새로 불러오지 않고 앱 창으로 옮긴다**(web.dev "Detection") → 처음 그린 설치 카드가 남아 새로고침해야 사라졌다. `appinstalled` 이벤트와 `display-mode: standalone` 변화를 들어 카드를 바로 숨김
  - Windows "설치된 앱" 크기: Edge는 설치 항목에 크기를 적고 Chrome은 적지 않는다(브라우저의 설치 등록 방식 차이). 앱 데이터는 두 경우 모두 브라우저 안에 저장되며 동작은 같음 — 앱에서 바꿀 수 없음
- 시험: vitest 116, e2e 10(+ 설치 안내: PC 설치 직후 카드 숨김, 데스크톱 모드 태블릿 → Chrome)

## 8. v0.10.3 — 안드로이드 설치 직후 혼선(실기기, 2026-10-20)

- 관찰: 태블릿 Firefox → [Chrome으로 열기] → Chrome [원큐합격 앱 설치] → 설치 창 확인 후 **브라우저 화면이 앱처럼 바뀌었는데**(v0.10.2가 설치 신호에 카드를 숨김) 앱 목록에는 1~2분 뒤에야 아이콘이 생김. 그사이 새로 고치면 다시 수동 설치 안내 → 설치하면 "이미 설치됨". 초보자는 브라우저 화면을 앱으로 오해
- 원인: 안드로이드 Chrome은 설치(WebAPK)를 누르면 설치 신호(`appinstalled`)를 바로 보내지만 실제 아이콘은 서버에서 만들어 1~2분 걸리고, PC와 달리 **브라우저 화면이 그대로 남는다**(web.dev "Detection"). 웹 페이지는 사용자가 연 브라우저 탭을 스스로 닫을 수 없다(window.close는 스크립트로 연 창만)
- 결정: 휴대폰·태블릿은 설치 신호 뒤 카드를 숨기지 않고 **"설치하고 있습니다(1~2분) — 지금 이 화면은 앱이 아니라 브라우저입니다 · 이 화면을 닫고 앱 목록의 원큐합격 아이콘으로"**로 바꿈. 이 브라우저에 설치 시각을 기억해 새로 고쳐도 같은 안내
  - 실제 설치 확인: manifest `related_applications`(webapp) + `navigator.getInstalledRelatedApps()`(안드로이드 Chrome)로 7.5초마다 확인 → 확인되면 **"설치 완료 — 앱 아이콘으로 여세요"**. 5분이 지나도 확인이 안 되면(지웠거나 실패, 확인 기능 없는 브라우저) 원래 설치 안내로
  - PC는 그대로(설치하면 지금 탭이 앱 창으로 옮겨지므로 카드 숨김)

## 9. v0.10.4 — 계산 문제 자동 분류 없앰(사용자 결정, 2026-10-20)

- 사용자 판단: 모든 문항의 보기 위에 [계산기] [메모]가 있으니 계산 문제인지 암기 문제인지 앱·전처리기가 가릴 필요가 없다 — 필요할 때 사용자가 고른다. 시스템을 단순하게
- 3절의 판정을 되돌림: `calc/detect.ts`(글자 추정), 계산 문제면 자동으로 열기, 설정 「계산 문제에서 계산기·메모 저절로 열기」, "계산 문제" 표시, 팩 스키마 flags `calc`·`no-calc`(아직 이 표시를 쓴 팩은 없음) 모두 삭제. **전처리기의 계산 문제 분류도 하지 않는다**
- 대신 [계산기] [메모]를 **아이콘이 있는 큰 단추**(높이 46px, 반씩, 열려 있으면 파란 면)로 — 모든 문항에서 눈에 띄게. 처음에는 닫혀 있고, 열어 둔 도구는 다음 문항에서도 열린 채(메모 내용만 새 장)
- 시험: vitest 115(판정 시험 삭제), e2e 10(계산 도구 시험을 단추로 여는 흐름으로 — 실제 팩 없이도 돎)

## 10. v0.10.5 — 풀이 화면 하단 2줄(사용자 의견, 2026-10-20)

- 의견: 하단 3줄([계산기] [메모] / 보기 / [모름] [쉬움])이 문제 영역을 좁힌다 → 2줄로. 시안 3차례(A 반반 · B 답 박스 넓게 · C 압축) 비교 후 사용자 승인
- 1줄 보기, 2줄 왼쪽 **[모름|쉬움] 박스**(모의고사는 [모름]만, 답한 뒤 [다음 →]) + 오른쪽 **[계산기|메모] 박스**(아이콘 + 글자). 박스 안 단추는 세로선으로 나눔
- 답한 뒤 휴대폰에서는 도구가 아이콘만(56px, 이름은 `aria-label`), [다음 →]이 넓게. 폭 900px 이상은 글자 유지
- 높이·간격 압축: 보기 54 → 46px(숫자 20), 둘째 줄 46px(글자 15·아이콘 18), 두 줄 간격 4px(맞닿지 않게 구분되는 최소), 하단 위·아래 여백 8·4px(안전 여백 최소 8px 유지). 누르는 크기는 44px 이상 유지
- 결과: 문제 영역이 현행 3줄보다 약 90px 넓음(412×915 기준 하단 196 → 약 110px)
- 시험: e2e 계산 도구에 배치 확인(보기와 둘째 줄 간격 ≤ 5px · 두 박스 한 줄 · 하단 높이 < 125px · 답한 뒤 아이콘만) 추가
