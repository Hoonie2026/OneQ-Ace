# 017. 문제팩 가져오기 — 진행 창·지연 안내·그만 가져오기·중단 안내

- 상태: 확정 (2026-10-20, 세션 #9) — 앱 v0.10.7
- 관련: ADR 002(가져오기·재연결), ADR 015(기기 범위: 태블릿·PC)
- 계기: 사용자 실사용 의견(태블릿) — 구글 드라이브에서 팩 30여 개를 고르면 안내 없이 홈 화면으로 돌아감. 10여 개로 줄여도 한동안 아무 표시 없다가 갑자기 완료.

## 원인

가져오기는 두 구간이다.

1. **파일 선택기 구간(OS 몫)**: 클라우드 파일을 고르면 기기가 파일을 **모두 내려받은 뒤에야** 브라우저가 앱에 넘겨준다. 이 동안 앱은 실행되지 않으므로 진행을 보여 줄 수 없다. 파일이 많아 메모리가 부족하면 브라우저가 앱 탭을 다시 시작한다 → "안내 없이 홈 화면".
2. **앱 처리 구간**: 파일마다 읽기 → 검사(압축 풀기·검증) → 저장. 전에는 단추 글자만 "가져오는 중…"으로 바뀌고 끝나면 4.5초짜리 알림만 떴다.

## 결정

1. **진행 창**(앱 처리 구간): 화면을 덮는 창에 `n / 전체`, 막대, 파일 이름, 단계(파일 읽는 중·검사하는 중·저장하는 중), 경과 초. 15개 넘게 고르면 "몇 분 걸릴 수 있음 — 화면을 끄거나 다른 앱으로 옮기지 마세요".
2. **지연 안내**: 한 파일이 20초를 넘으면 창 안에 "가져오는 데 시간이 오래 걸리고 있습니다 … 한 번에 가져오는 파일 수를 줄여서(10개 이하) 다시 시도" — 요청 문구를 따르되, 별도 팝업을 하나 더 띄우지 않고 진행 창 안 노란 상자로(창 위에 창이 겹치지 않게).
3. **그만 가져오기**: 지금 파일까지 저장하고 멈춤(저장 도중 끊으면 팩이 반쯤 들어갈 수 있어 파일 단위로). 결과에 "n개 중 k개까지 처리".
4. **결과 창**: 4개 이상 골랐거나 멈췄으면 알림 대신 확인 창으로 결과(새로 가져온 수, 건너뜀, 오류)를 보여 준다.
5. **중단 안내**(선택기 구간): 선택기를 열 때 `sessionStorage`에 시각을 남기고, 파일을 받거나 [취소]하면 지운다. 처리 중에도 남겨 두고 끝나면 지운다. 앱이 시작될 때 15분 안의 표시가 남아 있으면 "가져오기가 끝나지 않고 앱이 다시 시작된 것 같습니다 — 10개 이하로 나누거나 기기에 먼저 내려받기" 안내를 **한 번** 띄운다.
6. **느린 선택기 요령**: 선택기를 연 뒤 파일을 받기까지 15초 넘게 걸렸으면 결과에 "클라우드 파일은 기기에 먼저 내려받은 뒤 가져오면 빠릅니다".

## 검토한 대안

- 선택기 구간 진행 표시: 웹 앱은 OS 선택기의 내려받기에 접근할 수 없다(File System Access API도 같음) → 표시 대신 사후 안내.
- 한 번에 고를 수 있는 파일 수 제한(예: 10개): 기기에 내려받은 파일은 30개도 문제없이 들어가므로 막지 않고 안내만.
- 팩 여러 개를 zip 하나로 묶어 가져오기: 클라우드 내려받기 횟수가 1번이 되지만 묶음 파일이 커진다 — 실기기 P2 결과 보고 BACKLOG.
