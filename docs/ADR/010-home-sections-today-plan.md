# 010. 홈 구역 나누기 — 오늘 계획량을 한 묶음으로, 시험일 예상 점수 70점 미만이면 "계획 수정 필요"

- 상태: 확정 (2026-10-18, 세션 #6, 앱 v0.5.0)
- 관련: ADR 008·009, 실기기 v0.4.0 의견
- 코드: `ui/CoachCard.tsx`·`Home.tsx`·`Solve.tsx`·`Result.tsx`, `coach.ts`(`todayPlan`·`startToday`·`startRelearn`)

## 배경

실기기 v0.4.0(R1~R8)은 계획대로 동작. 사용자 의견 — 앱을 켰을 때 "지금 무엇을 해야 하는가"의 인지 부하를 더 줄이자:
"학습계획 ›" → "학습계획 설정 및 재설정 ›", 현재 점수와 예상 점수를 상자로 구분, 예상 점수는 **시험 당일 기준**으로 일관되게,
오늘 학습은 점수와 구역을 나누고 **계획한 오늘 학습시간**을 보이며 내용은 알고리즘이 정하게, 오늘 학습·과목별·모의고사 세 가지를 어떻게 고르게 할지 제안.

외부 사례: Duolingo는 여러 메뉴의 홈을 "따라가기만 하면 되는 길 하나"로 바꿨다(학습자들이 맞게 쓰는지 몰라서). 단 길 하나뿐이면 원하는 곳으로 가기 어렵다는 단점도 스스로 밝힘 → 추천 하나 + 다른 방법은 한 번 더 들어가서.

## 결정 (사용자 선택)

| # | 결정 |
|---|---|
| 1 | 홈 = 네 구역: ① [시험일 \| D-day](시험일 칸: "학습계획 설정 및 재설정 ›") ② [현재 점수] [시험일 예상 점수] 두 상자 ③ **오늘 학습**(계획 시간·문항 수, 알고리즘이 정한 구성, [오늘 학습 시작]) ④ "다른 방법 [과목 골라서] [모의고사]"(각각 다음 화면) |
| 2 | 예상 점수 이름 = **"시험일 예상 점수"**(학습계획대로 시험일까지 공부했을 때, ADR 008 실제 시험 기준). **70점 미만이면 "계획 수정 필요 ›" 배지**(누르면 학습 계획) |
| 3 | 오늘 학습 = **오늘 계획량 전체를 한 묶음**(오늘 학습시간 ÷ 문항당 시간 − 오늘 푼 수). 다 했으면 "더 학습하기(15문항)". 구성은 홈에 미리 보임: "오늘 틀린 문항 다시 n / 과목 복습 n · 새 문항 n"(상위 3과목) |
| 4 | 묶음을 다 풀면 그 묶음에서 틀린·모름 문항을 **바로 한 번 더**(같은 흐름, "방금 틀린·모름 문항 한 번 더" 표시). 그 뒤 성적 → [오늘 학습 마치기] [계속 학습하기] |
| 5 | 과목 카드 목록·모의고사는 홈에서 빼고 각각 한 화면 안쪽으로 |

## 영향
