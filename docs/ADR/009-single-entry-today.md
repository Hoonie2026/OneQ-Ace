# 009. 홈 단순화 — 오늘 학습 하나의 입구, 합격 가능성 카드 대신 "오늘 학습 마치기"

- 상태: 확정 (2026-10-18, 세션 #6, 앱 v0.4.0)
- 관련: ADR 008(과목별 + 모의고사, 실제 시험 기준 예상), 실기기 v0.3.0 결과(`docs/device-tests.md`)
- 코드: `ui/CoachCard.tsx`·`SubjectList.tsx`·`DaySummary.tsx`(신규)·`Home.tsx`·`Settings.tsx`·`Result.tsx`·`Solve.tsx`, `engine/session.ts`, `coach.ts`, `study.ts`

## 배경 — 실기기 v0.3.0 결과

- Q1·Q2: 홈이 너무 복잡. 시험일(왼쪽) | D-day(오른쪽)를 같은 크기로, 그 아래 "현재 점수 ☞ 학습계획 이행 시 예상 점수", 설명 문구·합격 가능성 카드 삭제.
  "이번 주 목표의 오늘 학습"과 "과목별 오늘 추천"이 헷갈림 → **오늘 학습 입구를 하나로**(틀린 문항 다시도 그 안으로). 문제팩은 설정으로(학습 중엔 필요 없음)
- Q3·Q4: 과목 카드가 "학습(15문항·복습 15)"인데 누르면 "낼 문항이 없습니다" — 원인: 같은 날 **모의고사로 푼 문항까지 "오늘 이미 푼 문항"**으로 빼서 세션이 비었고, 카드 숫자는 그 규칙을 따르지 않았음
- Q5: "오늘 학습 마치기"에서 현재 성적·계획대로 할 때 예상을 보여 주고 계획을 고칠지 묻기 — 합격 가능성 카드 대신
- Q6: 모의고사 ✕로 나가면 남은 시간이 멈추고, 이어서 열면 그때부터 흐르게
- Q7: 여러 회차 문제팩은 전처리기(2단계)에서 — 이후 확인

## 결정

| # | 결정 |
|---|---|
| 1 | 홈 카드 = **[시험일 \| D-day]** 같은 크기(시험일을 누르면 학습 계획) → **현재 ○점 ☞ 계획 이행 시 ○점**(설명 없음, 합격선 아래면 빨강·위면 초록·진단 전 무색) → **[오늘 학습 시작]** 하나 → "오늘 n / 목표 m문항 · 이번 주" + "오늘 학습 마치기 ›" |
| 2 | **오늘 학습 = 유일한 입구**: 15문항 = 오늘 틀린 문항(모든 과목) 다시 → 추천 과목(복습할 때가 된 것 → 출제빈도 높은 새 문항) → 모자라면 다음 순위 과목. 끝나면 "오늘 학습 계속" / "오늘 학습 마치기". 별도의 "틀린·모름 다시" 버튼과 "오늘 추천" 배지는 없앰 |
| 3 | 과목 카드는 "이 과목만"(작은 버튼): 과목만 골라 공부하고 싶을 때. 같은 규칙으로 구성, 카드의 "오늘 다시 n · 복습 n · 새 문항 n"은 세션 구성과 같은 함수(`availableCounts`)로 센다 |
| 4 | "오늘 끝" 규칙: 오늘 **정답을 보고 맞힌** 문항만 내일부터. 오늘 틀린 문항은 다시 낼 대상. **모의고사 풀이는 정답을 보지 않았으므로 오늘 끝으로 치지 않음** |
| 5 | **오늘 학습 마치기** 화면: 오늘 푼 문항·정답·모름, 과목별, 현재 ☞ 계획 이행 시, 합격선 아래면 "학습 계획을 고칠까요?" [학습 계획 고치기] [그대로 두고 마치기]. 합격 가능성 카드는 없앰 |
| 6 | 모의고사 ✕ = 멈춤(`pausedAt`), 이어서 열면 멈춘 시간을 마감에 더함(`pausedMs`). 앱을 강제로 닫으면 시간은 흐름 |
| 7 | 문제팩 목록·가져오기는 설정 화면으로(처음 문제팩이 없을 때만 홈에서 가져오기). 풀어 본 문항 수 표시는 없앰 |

## 영향

- 앱 v0.4.0. 엔진 본체·게이트는 그대로(세션 구성 함수만 추가)
- e2e: 3단계 게이트(오늘 학습 수 확인·문제팩 다시 가져오기는 설정에서), 5단계(오늘 학습 → 계속 → 마치기 → 과목만 → 모의고사 멈춤) 갱신
