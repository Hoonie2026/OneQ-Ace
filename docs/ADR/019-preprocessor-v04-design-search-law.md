## 결정

1. **화면**(`gui/theme.py`·`widgets.py`·`app.py`): 원큐합격 앱과 같은 색·로고·Pretendard 글꼴(OFL, `gui/fonts/` 함께 배포). 머리 띠 + 왼쪽(① 종목 ② 팩 정보) + 오른쪽(③ 기출 PDF) + 아래 실행 띠. 기본 묶음 상자(QGroupBox) 대신 카드(둥근 12px, 여백 20px) → 제목이 선에 걸려 잘리던 문제 제거. Qt Fusion 스타일 + 스타일시트(Windows 버전별 차이 없앰). 빈 목록은 끌어다 놓기 상자, 상태는 색 배지, 처리 속도는 "보통·빠르게·천천히", 표 열: 파일·시행일·팩 이름·법령 문항·상태·내용
2. **종목 검색**(`certs.py`, `gui/cert_picker.py`): 드롭다운 → 검색창 자동완성. 별칭(건안기·측량기사·철토기 …), 띄어쓰기·가운뎃점 무시, 출제기준 있는 종목 ✓. 데이터는 앱에 내장(인터넷 없이) — 공공데이터포털 CSV(`standards/qualifications.csv`, `qual-codes.csv`)가 있으면 600여 종목, 없으면 자주 쓰는 47종목
   - 출제기준이 없는 종목: 안내 + **[과목 직접 입력]**(`gui/profile_dialog.py`) → 사용자 폴더(`%APPDATA%\OneQ-Ace\standards`)에 프로필 저장(같은 코드면 사용자 것이 우선). [큐넷에서 출제기준 확인](종목코드 있으면 큐넷 종목 페이지, 없으면 검색)
   - **큐넷 화면 자동 읽기는 하지 않음**: 공개 API 없음, 자동 조회가 막혀 있음(세션 #9 확인), 구조가 바뀌면 깨짐
3. **과목 개편 요약**(`summary.py`): PDF를 넣으면 가장 옛 회차·최근 회차 1~2개의 과목 머리말을 실제 추출기로 읽어(백그라운드 1~4초) "PDF 과목 6개 → 현행 5과목 100문항 · 합쳐짐 · 이름 바뀜 · 빠짐 · 출제기준에 없는 과목명 · 구기준 회차 수"를 처리 **전에** 보여 줌
4. **법령·기준 문항 표시**(`lawtag.py`, `standards/law-terms.json`): 문항 글에서 ① 법령 이름(…법령상·…에 관한 규칙·…시방서 등, 띄어쓰기 든 이름·고시는 knownLaws) ② 종목별 법정 제도 낱말(안전관리자·안전보건관리비·도급·측량업·과태료 …) ③ 지정 과목의 "수치+단위 이상·이하" 기준 → 팩 문항 `flags: law`, `lawRefs: [법령명]`. **팩 포맷 변경 없음**(oqp/1에 칸이 있었음)
   - 실측: 건설안전 59회차 7,080문항 중 1,065(15.0%) — 산업재해 예방 21%, 건설공사 안전관리 36%, 건설재료 0.2%. 측량 약 5%. 일반 낱말("하여야 한다")·공법·방법 이름은 넣지 않음(경고를 안 보게 되므로)
   - 결과 카드: "법령·기준 관련 n문항(k%) · 5년 넘은 회차 m개 — 앱에서 답한 뒤 '현행 기준 확인' 안내". 검수 창에 "법령·기준 문항" 보기와 배지
   - **팩 판 기본 2**(`--pack-version` 기본 2): 법령 표시가 든 판. 앱은 1판을 자동으로 교체하고 학습 기록을 이음(ADR 002) — 같은 판 다른 내용이면 파일마다 묻는 창이 뜨는 것을 피함
5. 단정적 경고 문구("합격할 수 없는 치명적 위험")와 확인 안 된 개정 수치 예시는 쓰지 않음. "최근 5개년 CBT 기출 확보" 권고는 기사 CBT 기출 비공개(2022-2 이후)라 넣지 않음
