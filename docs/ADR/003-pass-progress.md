# 003. 회독(pass) 하나로 진도·이어 풀기·성적 통일 (3단계 실기기 1차 피드백)

- 상태: 확정 (2026-10-15, 세션 #3)
- 관련: ADR 002, 개발기준서 4.2·6.5·7.1, device-tests 3단계 S3·S6·S9·S10

## 배경 (v0.1.0 실기기 결과)

- S3 NG: 과목을 고를 때마다 새 묶음을 만들고 같은 팩의 다른 과목 묶음까지 닫아서, 과목을 오가면 진행이 0으로 돌아갔다.
- S3 NG: 회차 전체·과목별 묶음이 각자 푼 문항 목록을 따로 가져, "이어 풀기 11/100"과 "진도 31/100"이 달랐다.
- S6 요청: 결과를 다 푼 뒤가 아니라 풀이 중에도 실시간으로 보고 싶다.
- S10 요청: 자격종목이 여럿이면 종목별로 나눠 학습, 같은 종목 회차 추가 시 기록 유지, 이미 있는 똑같은 팩은 건너뛰기.

## 결정

1. **팩마다 진행 중인 회독 하나.** 회차 전체로 풀든 과목별로 풀든 같은 회독에 쌓인다. 화면의 진도·이어 풀기 숫자·성적은 모두 이 회독에서 나온다.
2. **진행 상태는 원장(attempts)에서 계산한다.** 회독 시작 이후의 풀이(오답 다시 풀기 제외) 중 문항별 마지막 것. 따로 저장한 목록이 없으므로 서로 어긋날 수 없다. `runs.answered`는 참고용으로만 남긴다.
3. **이어 풀기 = 안 푼 첫 문항.** 위치를 저장하지 않으므로 앱 종료·과목 전환과 무관하다. 이전 문항으로 돌아가 다시 볼 수 있고, "다음"은 다음 안 푼 문항으로 간다.
4. **성적은 언제든.** 풀이 화면 위 "성적" 버튼과 홈의 "성적" 버튼. 다 풀기 전에는 과목별 정답률(푼 문항 기준), 다 풀면 시험 점수(전체 문항 기준). 합격선 판정은 회차 전체에서, 다 풀기 전에는 모든 과목을 5문항 이상 풀었을 때만.
5. **새 회독**: 다 푼 뒤 "처음부터 다시 풀기"로 시작. 이전 회독 기록은 원장에 그대로. 첫 회독은 회독이 생기기 전 기록도 포함(v0.1.0 데이터 이어받기).
6. **오답·모름 다시 풀기**는 회독과 별개 묶음. 중간에 나가면 같은 묶음을 이어 풀고, 다 풀면 닫힌다. 회독 진도에는 섞지 않는다.
7. **자격종목 선택**: 팩의 `cert.code`로 나눠, 둘 이상이면 홈 위에 종목 버튼. 고른 종목은 기기에 기억(백업에는 넣지 않음). 같은 종목의 다른 회차는 그대로 추가되고 기록은 회차별로 유지.
8. **같은 팩 다시 가져오기**: packId·버전·모든 파일 해시가 같으면 묻지 않고 건너뛴다("같은 팩 N개 건너뜀"). 같은 버전인데 내용이 다르면 확인 후 교체(기록은 ADR 002 규칙으로 이어짐). 더 높은 버전은 교체.
9. **이 기기 데이터 지우기**(설정): Android에서 앱 아이콘을 지워도 데이터가 Chrome에 남으므로, 복원 시험·기기 양도용으로 둔다.

## 영향

- DB 구조 변경 없음(runs의 mode 'subject' 묶음은 더 만들지 않음). 백업 형식 변경 없음.
- 4단계 세션 구성(6.5)은 회독과 별개의 "오늘의 학습" 묶음으로 추가한다.
