# ADR 025 — 단원별·유형별 학습을 없애고, 학습앱에서 출제기준을 보여 준다

- 상태: 결정·구현(사용자 2026-11-16 실기기 시험) · 앱 v0.16.0~0.16.2, 생성기 0.5.0-dev.17~dev.19. ADR 021 4절(단원·유형 분류와 단원별·유형별 학습)을 **통째로** 대체

## 배경

- 사용자: 단원별 학습은 **분류 정확도와 실효성 면에서 실익이 없다** — 과목별 학습은 유지
- 사용자: 학습앱에서 **선택 종목의 출제기준을 확인**할 수 있으면 좋겠다
- 사용자: 과목별 학습 화면의 과목명·[학습하기] 줄바꿈, 글자 크기, 색이 직관적이지 않고 과목마다 모양이 달라짐(과목명 길이에 따라 단추가 오른쪽·아래로 갈림)

## 결정

1. 학습앱에서 **단원·유형별 화면(`SubjectDetail`)·답한 뒤 "이 문제 단원은?"(`UnitAsk`)·설정의 단원 묻기 켜기/끄기·`units.ts`를 없앤다**. 학습 방식은 시스템 추천·과목별·모의고사 셋
2. **출제기준 화면**(`ui/StandardView.tsx`): 홈의 [출제기준] 카드와 과목별 학습 아래 [이 종목 출제기준 보기]에서. 이 종목 문제팩 중 세부항목이 있고 가장 최근 회차인 팩의 manifest에서 — 적용 기간 · 과목 수·문항 수 · 합격 기준 · 과목별 주요항목 → 세부항목(펼치기)
3. 팩 형식: `manifest.standard`를 **항상** 기록하고 `period`(적용 기간 from·to)를 더함(`shared/pack-schema.json`). 이전 팩은 기간 대신 "○○ 기준" 또는 "기록 없음"
4. 과목별 학습 화면: **한 줄 전체가 단추** — 번호 · 과목명(위) · "n문항 풀기"(아래, 파란 글자) · ›. 과목명 길이와 관계없이 같은 모양
5. **정합성(dev.19, 사용자 — 생성기 진행 칸에 '단원 대기'가 남아 있음)**: 생성기에서도 문항별 단원·유형 분류를 없앤다 — `classify.py`·`unitlearn.py`·`standards/unit-keywords.json` 삭제, 처리 단계 '분류'·'단원 학습'·'단원 대기' → **읽기 · 문항 나누기 · 정답 · 정답 확인(다른 회차와 교차 확인, ADR 024) · 팩**(준비가 끝나 다른 회차를 기다리면 '팩 대기'), 결과 화면의 유형·단원 줄, 끝난 뒤 '단원 확정 n%', 검수 파일의 units·types, 명령줄 `--no-learn` 삭제. 팩 문항에 `unit`·`qtype`·`sequence`·`classifyUnsure`·`unitCandidates`를 더는 쓰지 않음(형식에는 옛 팩을 읽으려고 선택 칸으로 남음). 문항 내용이 바뀌므로 다시 만든 팩은 판이 하나 올라 학습앱이 자동 교체(기록 이어짐) — 이때 출제기준 적용 기간도 함께 들어옴
6. 남는 '세부항목'은 출제기준 그 자체(팩 `subjects[].units` = 주요항목·세부항목)로, 학습앱 '출제기준' 화면에만 쓴다. 생성기 종목 정보 줄은 '단원 n개' → '세부항목 n개'
7. 학습앱의 남은 흔적도 정리: 몰아 풀기 묶음(`run.bundle`)과 결과 화면의 '섞어서 풀기' 안내 삭제(단원·유형별 학습에서만 쓰던 것)
