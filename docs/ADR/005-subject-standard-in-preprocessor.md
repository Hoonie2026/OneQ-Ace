# 005. 출제기준(과목 구성) 정리는 전처리 단계에서 — 학습앱은 과목명만 따른다

- 상태: 확정 (2026-10-15, 세션 #3). **구현 완료(2026-10-18, 세션 #7 — ADR 012)**: `preprocessor/standards/`, `manifest.excluded`·`standard`, 2011 재배정 제안+검수
- 관련: ADR 001(oqp/1), ADR 004, 개발기준서 4.1·5.1·5.2

## 배경

과목 통합을 과목명으로 하기로 했다(ADR 004). 남은 문제는 출제기준 개편이다.
- 폐지 과목: 철도토목기사는 5과목 → 4과목으로 바뀌며 건설재료가 빠졌다. 기출 PDF에는 건설재료가 들어 있지만 현행 시험에 나오지 않으므로 **학습할 이유가 없다.**
- 이름만 바뀐 과목: 같은 과목이 연도마다 다른 이름으로 적혀 있을 수 있다.

학습앱에서 이를 묻고 고르게 하면 사용자마다 같은 판단을 반복하고 화면이 복잡해진다. 팩은 담당자가 한 번 만들어 게시판으로 나누므로 **전처리에서 한 번 정리하면 모든 사용자에게 적용된다.**

## 결정

1. **종목별 출제기준 프로필**(전처리기 설정 파일, 예: `preprocessor/standards/RAILCIVIL.json`)
   - 현행 과목 목록: 과목명(표준 이름)·순서·문항 수, 적용 시작 연도
   - 별칭: 연도별로 다르게 적힌 과목명 → 표준 이름
   - 제외 과목: 현행에 없는 과목명(예: 건설재료)
2. **전처리기**는 PDF의 과목 머리말을 프로필로 매핑한다. 별칭은 표준 이름으로 바꾸고, **제외 과목 문항은 팩에 넣지 않는다.** 프로필에 없는 과목명이 나오면 검수 화면에서 경고하고 사람이 고른다(표준 과목에 연결 / 제외).
3. **팩에는 현행 기준으로 다듬은 결과만** 들어간다. manifest에 무엇을 뺐는지 기록한다(`excluded`: 과목명·문항 수·사유). 원래 시험지 문항번호(`no`)는 유지한다(풀이 화면의 "○번" 표기가 원본과 같게).
4. **학습앱은 과목명을 그대로 따른다.** 별칭·폐지 과목을 묻거나 판단하는 화면을 두지 않는다. 학습앱의 삭제 기능은 종목 단위(합격 후)만 둔다.

## 팩 포맷 영향 (2단계에서 ADR 001 보완)

- 제외 과목이 있는 회차는 문항이 100개가 아니고 번호가 이어지지 않는다(예: 철도토목 구기준 회차 → 80문항, 21~40번 없음). 지금 검증기는 번호 연속(`NUMBERING`)을 요구하므로 manifest `excluded`에 적힌 범위만큼 빈 번호를 허용하도록 스키마·두 검증기·공용 시험을 함께 고친다.
- 학습앱의 회차 진도·점수는 팩에 든 문항 기준이라 그대로 동작한다(80문항이면 80문항 기준).
- 이미 만든 측량 34회차 팩: 4단계 첫 작업의 과목명 대조에서 바뀐 과목이 없으면 그대로 쓴다. 있으면 프로필을 만들어 다시 전처리(packVersion 2)하고, 학습 기록은 ADR 002 규칙으로 이어진다.

## 검토했으나 보류

- 학습앱에서 사용자가 폐지 과목을 지우거나 별칭을 고르기: 사용자마다 같은 판단을 반복, 앱이 복잡해짐(사용자 의견으로 기각)
- 폐지 과목 문항을 팩에 남기고 표시만 숨기기: 용량 낭비, 앱마다 숨김 처리 필요

## 추가 — 측량 34회차 과목명 대조 결과 (2026-10-15, 세션 #4)

- **과목 머리말 표기**: 34회차 모두 같은 5과목·같은 순서·과목당 20문항(측지학 및 위성측위시스템 / 응용측량 / 사진측량 및 원격탐사 / 지리정보시스템 / 측량학). 이름 변경·폐지 과목 **없음**.
- **그러나 2011년 3회차(20110320·20110612·20111002)는 머리말과 내용이 다르다.** 다른 회차와 문항 유사도로 대조하면
  - 41~60번("사진측량 및 원격탐사"): 사진측량·원격탐사와 지리정보시스템 문항이 섞여 있음
  - 61~80번("지리정보시스템"): 실제로는 측량학(측량 일반) 문항
  - 81~100번("측량학"): 측량관계법규 문항(현행 측량학에 포함)
  - 즉 2011년은 과목 구성이 현행과 달랐고(2012년 개편 추정), PDF 제작처가 현행 과목명을 붙였다. 2012년 이후 31회차는 내용과 머리말이 맞는다(회차당 불일치 0~3문항은 과목 경계 주제).
- 영향: 과목명만 보는 별칭 규칙으로는 못 고친다(한 구과목이 두 현행 과목으로 갈림). 이미 만든 2011년 팩 3개는 과목별 통합·예상 점수에서 **GIS 20문항이 측량학으로, 사진/GIS 혼합 20문항이 사진측량으로** 잘못 들어간다(전체 3,400문항 중 60문항, 1.8%).
- **2단계에 추가할 일**: 출제기준 프로필에 "구기준 회차 → 문항별 과목 재배정"을 둔다. 자동 제안(현행 회차와의 문항 유사도) + 검수 화면에서 확인. 결정 전까지 학습앱은 팩의 과목명을 그대로 따른다(이 ADR의 원칙 유지).
