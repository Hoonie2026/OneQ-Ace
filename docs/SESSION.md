### 실기기 1차 결과 (2026-10-15)
- v0.1.0을 Android에 설치하자 회차 풀기·과목별에서 검은 빈 화면 → PC Chrome 155로 재현, 원인은 Chrome 150대의 `scrollTo()` Promise 반환(device-tests 발견 사항). **v0.1.1에서 수정**, 오류 화면(ErrorBoundary)과 회귀 시험 추가
