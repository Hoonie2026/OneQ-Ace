# OneQ-Ace (원큐합격)

기사·산업기사 **객관식 필기** 학습앱. 시험일까지 남은 기간과 내 풀이 기록을 분석해 오늘 풀 문항을 골라 주고, 기출을 반복해 과락과 미학습을 줄입니다.

> 이름: **OneQ**(원큐, 한 번에) + **Ace**(에이스) — "한 번에 합격"

- **앱 주소(설치)**: <https://hoonie2026.github.io/OneQ-Ace/>
- 서버·회원가입·외부 API 없음. 모든 학습 기록은 기기 안에만 저장됩니다.
- 앱에는 문제가 들어 있지 않습니다. 학습자가 가진 기출 PDF를 **원큐합격 문제팩 생성기**(PC)로 문제팩으로 바꿔 넣습니다.

## 구성

| 폴더 | 내용 |
|---|---|
| [`app/`](app) | **학습앱** — 정적 PWA(Vite + React + TypeScript). 안드로이드·아이폰·태블릿·PC. 학습 엔진은 `src/engine/`(FSRS 간격 반복, 과목 배분, 시험일 예상 점수) |
| [`preprocessor/`](preprocessor) | **원큐합격 문제팩 생성기** — Windows 창 프로그램(Python, PySide6). 큐넷 출제기준 조회, 기출 PDF(텍스트·스캔) → 문제팩 |
| [`shared/`](shared) | 문제팩 포맷 스키마(`pack-schema.json`, oqp/1)와 두 검증기(앱·생성기)가 함께 쓰는 시험 사례 |
| [`docs/`](docs) | 사용 안내, 결정 기록(ADR), 엔진 검증 결과 |

## 주요 기능

**학습앱**
- 학습 계획(시험일·주당 학습일·하루 학습시간·특정 날짜 시간) → 오늘 학습 목표
- 학습 방식: 시스템 추천 · 과목별 · 회차별 · 모의고사
- 문항마다 FSRS로 다음 복습 날짜 계산(복습은 하루 분량의 최대 60%), 틀린 문항 바로 다시 풀기, 과락 위험 과목에 새 문항 더 배분
- 시험일 예상 점수(기출과 같은·변형·신규 문항으로 나눠 계산, 학습기록이 쌓인 뒤 표시)와 계산 근거 화면, 학습 원리(연구 근거) 화면, 출제기준 보기
- 정답이 없거나 불확실한 문항은 학습자가 정답 지정·고치기
- 공학용 계산기·손글씨 메모, 백업/가져오기(기기 간 이어 하기), 라이트·다크 모드

**문제팩 생성기**
- 큐넷 출제기준 자동 조회 → 현행 과목·문항 수
- 2단 배치·쪽 넘김·과목 상자·옛 과목 개편을 처리해 문항 나누기, 정답 표시 지우기, 같은 문항 정답 교차 확인
- 스캔 PDF는 Windows 내장 한국어 OCR
- 종목당 zip 하나로 묶고, 카카오톡·메일로 공유

## 개발

```bash
cd app
npm install
npm run dev        # http://localhost:5173/OneQ-Ace/
npm test           # 단위 시험(vitest)
npm run e2e        # 화면 시험(Playwright, 처음 한 번 npx playwright install chromium)
npm run gate       # 학습 엔진 검증(가상 학습자 × 시험까지 기간 × 시드) — docs/engine-gate.md
npm run build
```

생성기는 [`preprocessor/README.md`](preprocessor/README.md).

`main`에 푸시하면 GitHub Actions가 학습앱을 GitHub Pages에 배포합니다. 생성기 설치 프로그램은 `prep-v*` 태그 릴리스에서 빌드됩니다.
